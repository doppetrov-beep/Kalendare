# ⚔ Сбор пати — планирование D&D по часовым поясам

Отдельный раздел репозитория `Kalendare`. Личный календарь смен в корне сайта **не затронут**.

**Сайт:** https://doppetrov-beep.github.io/Kalendare/dnd/

## Возможности

- **Только ник**, без почты и пароля: используется анонимная авторизация Supabase.
- Создатель организует комнату и отправляет друзьям длинную секретную ссылку.
- Участники отмечают интервалы по **своему местному времени**, в том числе разные даты и часы.
- Время сохраняется в UTC; каждый видит даты, часы и предложения в своём часовом поясе. Часовой пояс определяет телефон/браузер.
- В комнате до **12 участников** (ориентир — ваша компания из 6 человек).
- Общий планировщик предлагает 2, 3 или 4 часа игры и показывает лучшие пересечения на следующие 21 день. Если полного совпадения нет, показывает частичные варианты и кто ещё не может.
- Игроки видят состав комнаты и отмеченные интервалы друг друга в агрегированном виде, могут удалять свои интервалы; другие игроки не могут редактировать чужие данные.
- Обновление ответов автоматически примерно каждые 20 секунд или по кнопке. Нужен интернет.
- Вход с другого телефона создаёт *нового* анонимного участника. Ник не является удостоверением личности.

## Состояние подключения (30 октября 2026)

- GitHub Pages: сайт опубликован (без оплаты).
- Supabase: **DND-Party-Scheduler**, регион **eu-central-1 (Франкфурт)**, Free **0 USD/мес.**
- База данных создана: `dnd_rooms`, `dnd_members`, `dnd_windows`, политика RLS и RPC `join_room`.
- В `config.js` записаны только публичные параметры **Supabase Project URL** и **publishable key**. Никакие секретные ключи не публиковались.
- **Обязательно проверь включение Anonymous Sign-Ins** в [Authentication → Providers](https://supabase.com/dashboard/project/yxpkmbckediniyuomvbs/auth/providers). Это единственное условие входа по одному нику. Подключение ChatGPT к Supabase не даёт возможности изменить настройку Auth Providers.
- Затем откройте [сайт](https://doppetrov-beep.github.io/Kalendare/dnd/), введите ник, создайте комнату и отправьте ссылку друзьям. Проверьте вход с другого телефона или браузера.

Если Supabase временно недоступен или Anonymous Sign-Ins отключён, общий обмен данными не работает. Сохранённые интервалы остаются в Supabase, но сайт не может получать обновления.

### Как сохранить бесплатный проект надолго

На Free-плане малoактивный проект может быть автоматически приостановлен. По [документации Supabase](https://supabase.com/docs/guides/platform/free-project-pausing), проект, приостановленный из-за неактивности, можно восстановить через панель в течение **90 дней**; затем автоматическое восстановление на платформе не гарантируется. После месяца или двух без игр проверяйте проект в панели, а при длительных перерывах заранее сохраняйте нужные расписания. Гарантий вечной бесплатной работы нет.

### Ограничения и приватность

- Личность определяется анонимной сессией в браузере. После очистки данных Safari, переустановки или смены телефона восстановить такую сессию без отдельной регистрации нельзя. Один и тот же ник можно ввести на нескольких устройствах; сайт посчитает их разными людьми.
- Секретная ссылка служит доступом к комнате. **Не публикуйте её открыто.** Это не полноценная закрытая система с подтверждением личности.
- Система сохраняет свободное время в базе Supabase и **не является офлайн-приложением**. Если база недоступна, синхронизация не работает.
- Планы Supabase Free имеют квоты и могут **приостанавливаться после периода низкой активности**; при этом GitHub Pages продолжает отдавать интерфейс.
- На проекте Supabase рекомендовано добавить CAPTCHA/Turnstile против автоматического создания анонимных аккаунтов.
- Для часовых поясов используется `datetime-local` телефона и локальный `Date`, затем UTC, чтобы все интервалы сравнивались как одни и те же моменты времени. Ввод и отображение следуют часовому поясу устройства (при путешествии пересчитаются).

## Структура

- `index.html` — мобильный интерфейс
- `style.css` — оформление
- `app.js` — комнаты, авторизация, интервалы, подбор совпадений
- `config.js` — **только публичные** параметры Supabase
- `schema.sql` — SQL + RLS права

## Лицензия и деплой

Полностью статический сайт, без build step и без платной подписки для самого GitHub Pages. GitHub Pages публикует содержимое ветки `main` из корня репозитория (Settings → Pages → Deploy from a branch → main → /(root)).
