Quality Test

This test checks the power balance of the separate laser modules and resets the power to the working point if necessary.

The quality test is used for a final assessment of set Suprasetter parameters and imaging quality.

Use a screen matched to potential plate restrictions for the quality test.

The AGFA Azura plate, for example, has been released for a screen ruling of 80 lines/cm only. In this case, select the "Quality test for low-resolution material" option in the "Quality Test" tab (IS Classic, 100 l/cm).

Select the "Quality test for high-resolution material" option for high-resolution plates such as Kodak DITP Gold since otherwise the quality assessment for FM screens is insufficient.

Quality test for positive plates

Imaging of the Quality Test

Start the quality test by clicking the "Start quality test" button.

Evaluation of the Quality Test

It is vital for quality test evaluation to perpendicularly view the plate since an oblique viewing angle may lead to a false impression of brightness.

For the same reason you must choose an illumination that prevents reflections on the plate surface from reaching the viewer's eye.

We recommend a viewing distance of not less than 30cm.

Checking the working point

To check the working point, evaluate the scales for power balance imaged by every module. Compared to the balance test the patch where diamond and background merge must not have changed. In the adverse case you must proportionally adapt the power for all modules.

As a rule, you will have to reduce the power. Instead of decreasing the power you could also proportionally increase the speed (see the calculation example 7.3 below).

For positive plates you must finally check on the quality test tab if the plate background in the non-printing areas is completely empty.

You can do this with the microscope. The so-called acetone test, however, is optimal. Apply a drop of acetone on a sufficiently large non-printing area (burn-out area or gray scale 0% patch). The acetone will dissolve coating residues and deposit them as a typical ring at the edges of the dispersing drop. The described ring may be faintly visible only. The plate background is not sufficiently clean if a ring colored like the plate coating is clearly visible.

In this case you must either increase the power, or plate development is not optimal.

Checking the module alignment

There is a step gray wedge and a gradation wedge on each module border. There must not be any visible density jump at the module borders in any of the gray wedges. This applies to all tonal levels; there must be no visible density jump between any of the modules.

Checking the geometric module alignment

The gray scales for the quality test are used to check the geometric alignment of the modules' imaging ranges.

The module border is roughly in the gray scale middle. In this area, there must not be any visible, printing hairline (dark, colored like the plate coating).

In such a case you must correct the position of the module to the right of the module border you are looking at.

Increase the position by one unit for positive plates. You must also increase the position by one unit for all modules to the right of the corrected module since otherwise the geometric alignment error would be shifted to the respective neighboring module to the right.

For negative plates you must reduce the positions of modules to the right of the border to be corrected by one unit.

A minor bright, non-printing line can be tolerated since it will probably be invisible in the printed product.

Quality test for negative plates

To evaluate the quality test for negative plates, it must be proof printed.

Imaging of the quality test

To punch the plates, make the following settings in the "Punch mode" tab of the Material Wizard:

  • "Always use recorder punch settings"
  • a punch setup suited to proof printing.

Start the quality test by clicking the "Start quality test" button.

Evaluation of the Quality Test

Evaluation of the quality test page is like with positive plates. It is not possible to check the working point since the fine screens of the power test scale suffer from dot gain during printing and cannot be evaluated.

Calculation example for working point alignment

Set the following values after power balancing:

Module A = 83.4; B = 91.4; C = 89.0; D = 87.4; E = 87.4; F = 87.4

Speed: 235rpm

The previous match patch was patch 9

After power balance, the match patch is patch 8

From the power test you can establish that a change by one patch is effected by a power change of ca. 4 mW.

There are two ways to restore the previous working point:

1. Proportional power reductions:

the average module power PM is

PM = (PA+PB+PC+PD+PE+PF)/6

PM = (83.4+91.4+89.0+87.4+87.4+87.4)/6

PM = 87.67 mW

ΔP = 4 mW

X = (PM - ΔP)/PM

X = (87.67 mW - 4 mW) / 87.67 mW

X = 0.954

Pnew = Pold * X

PAnew = PAold * X = 83.4 mW * 0.954 = 79.6 mW

PBnew = PBold * X = 91.4 mW * 0.954 = 87.2 mW

PCnew = PCold * X = 89.0 mW * 0.954 = 84.9 mW

PDnew = PDold * X = 87.4 mW * 0.954 = 83.4 mW

PEnew = PEold * X = 87.4 mW * 0.954 = 83.4 mW

PFnew = PFold * X = 87.4 mW * 0.954 = 83.4 mW

2. Proportional drum speed increase:

the average module power PM is

PM = (PA+PB+PC+PD+PE+PF)/6

PM = (83.4+91.4+89.0+87.4+87.4+87.4)/6

PM = 87.67 mW

ΔP = 4 mW

X = (PM - ΔP)/PM

X = (87.67 mW - 4 mW) / 87.67 mW

X = 0.954

Ddrumnew = Ddrumold / X = 235 rpm / 0.954 = 246 rpm

Type the new power or the new speed values in the respective fields in the Material Wizard.

To verify the new working point, you should image a quality test.

Align Imaging to the Punches

This quality test also lets you measure and optimize alignment of imaging to the punches.

Proceed as follows:

1. Measure distances 1, 2 and 4 on an imaged plate using a microscope with hundredfold magnification.


2. Enter the values measured for the distances into the appropriate boxes in the "Quality Test" tab.

3. For "Distance 3", select the punch that is built into your device.

4. Click "Calculate". The values calculated for alignment of the imaging position to the punches are entered in "Current Values".

5. Select whether you want to run the quality test for high-resolution material or material with a lower resolution.

6. Click "Apply". The current values are sent to the recorder and used for the imaging runs that will follow.

7. Start the quality test for the set material by clicking the "Start quality test" button.

8. Develop the printing plate.

9. Check the imaged plate:

If imaging is aligned optimally to the punches, half of the lines for distances 1, 2 and 4 are cut off by the punches, i.e. the lines still have a thickness of 50 µm at the punch.

If imaging isn't aligned optimally to the punches, you must measure distances 1, 2 and 4 again and repeat the test.
