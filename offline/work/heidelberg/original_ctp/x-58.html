System Wizard (4) Reference Temperature

You must determine the reference temperature of the laser module in this tab. The other tests are based on this reference temperature.

The reference temperature may only be determined when the Suprasetter A52/A74/A75 has reached its operating temperature. You cannot see a thermometer and the Suprasetter is red in the main view if the operating temperature is not yet reached. A message is also displayed.

Set Temperature

Click this button to set the "New Reference Temperature" as the current temperature in the "Current Reference Temperature" section and send it to the recorder where it is enabled.
