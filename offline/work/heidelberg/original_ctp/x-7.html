Vertical Menu Bar

Unload Material

Suprasetter as a semi-automatic device:
Clicking this icon transports the plate back onto the insertion table. The plate exits to the conveyor if a conveyor is connected.

Suprasetter with the Auto Plate Loader:
Clicking this icon outputs the plate to the conveyor.

You can only select this function if the device status is READY.

Load material

Clicking this icon conveys the plate from the Auto Plate Loader, or the insertion table if you run the Suprasetter as a semi-automatic device, into the imaging drum.

You can only select this function:

  • if the device status is WAIT, PREPARE or TRANSMISSION.
  • if material is selected in the Input dialog (Material Wizard 1).
