Parameter Editor (1)

In this tab, you can view all the parameters used for operation of the recorder. You can restrict the parameters shown by selecting a dataset and assigning an attribute. Some parameters only appear if the relevant operating mode was set in the "Operating Mode" tab. The parameters are displayed in a table whose columns have the following meaning:

  • FID: Dataset Identification number
  • PID: Parameter Identification number
  • Name: Name of the parameter
  • Value: Current parameter value set

Dataset Selection

One or all data set(s) whose parameters are to be displayed in the table can be selected in this list box.

The following datasets are available:

  • All: If this is selected, all the parameters from all five datasets in the table are displayed.
  • Application: All parameters which are required for the resolution and geometry for one exposure process. These parameters are valid just for one exposure run.
  • Action: All parameters which are required for accompanying actions for an exposure process, such as cutting, punching and material transport are displayed. These parameters, too, are also valid just for one exposure run.
  • Material: All parameters describing material properties are listed. They include, for example, the material geometry, material type or resolution-dependent exposure data.
  • Static: All the machine-specific parameters are compiled here, such as available resolutions, geometry data or configuration parameters.
  • Measure: All the values determined are compiled here. They are values that can be changed (length counter, time) and static values (configuration queries, limit values) that are determined by the machine and made available in this dataset.

Attribute

This list box lets you restrict the choice of parameters shown even further. The following parameter attributes are available:

  • None: If this is selected, all the parameters of the selected dataset are displayed without any restrictions.
  • Factory: All parameters which are saved during a "Save Configuration" action are displayed.
  • Restore: Only those parameters which are overwritten by new values after a software update are displayed.
  • Geometry: This attribute defines whether or not the parameters shown are geometry parameters. Only these are shown.
  • Lifetime: If this is selected, all lifetime parameters are displayed.
  • Non Volatile: If this is selected, all non-volatile parameters are displayed.
  • Restore Never: These values are never restored. They are only temporary values determined during the runtime.

Search for

A parameter identification number can be entered in the left box above the PID column. All parameters containing this combination of numbers are listed. A parameter name or part of it can be entered in the right box above the "Name" column. All parameters containing this combination of characters are listed.

You can search for either a parameter identification number or for a parameter name but not for both at the same time.

You can sort the parameters shown in the table in ascending or descending order by their PID or their name. To do this, click the respective column header with the mouse. The sorting order can be changed by clicking it once again:

  • Sort in ascending order
  • Sort in descending order

Edit...

The "Edit..." button can be used if you selected a row in the table with the mouse. A dialog then appears where you can edit the selected parameter (see the Parameter Editor (2) tab). Some parameters can only be edited if the relevant operating mode was set in the Operating Mode. A double click on a row also opens the dialog box for editing a parameter.

Sending...

When you click "Sending...", all the parameter data in the table are loaded from the recorder and a dialog box appears from where you can send the parameters by e-mail.

Save on PC

When you click "Save", all the parameter data in the table are loaded from the recorder and saved to a file on the GUI computer.

Loading...

The "Loading..." button opens a dialog with which a certain parameter dataset can be loaded from the hard disk or diskette and displayed in the table. This function is only enabled in the "Service" or "Research and Development" mode.

Apply

Click "Apply" to download the dataset loaded beforehand to the recorder and save it permanently.

In the "Service" or "Research and Development" mode, clicking this button permanently saves the datasets that were loaded beforehand from the hard disk or disk with the "Load" button.
