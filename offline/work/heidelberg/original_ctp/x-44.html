Parameter Editor (2)

The parameter values can be edited in this tab. Different information about the parameter shown is displayed here. Depending on the operating mode, some parameters may be visible but cannot be edited.

  • FID: Identification number of the dataset in which the parameter is located (1 = Application, 2 = Action, 3 = Material, 4 = Static, 5 = Measure).
  • PID: ID of the parameter.
  • Name: Name of the parameter.
  • Description: Description of the parameter functionality.
  • Attribute: Additional information about the parameter
  • Minimum Value: Minimum parameter value
  • Maximum Value: Maximum parameter value
  • Default value: Parameter default value

The new parameter value can be entered in the text box. The value must neither exceed nor fall below the minimum and maximum values. The "Research and Development" mode does not feature a limit value check.

  • Unit: Parameter unit, e.g. µm

Apply

When you click "Apply", the settings are sent to the recorder and enabled, but they will not be saved permanently (e.g. after a power failure). The "Parameter Editor (1)" tab displays again.

Note: The settings are only saved if you clicked "Apply" in the "Parameter Editor (1)" tab.

Cancel

Your last inputs are undone by clicking "Cancel" unless the "Apply" button was clicked.
