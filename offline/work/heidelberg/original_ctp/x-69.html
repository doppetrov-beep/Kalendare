Heidelberg Remote Service

The Remote Service offers you fast assistance in queries you may have on operation. Remote access to the Suprasetter A52/A74/A75, that you must give your approval to, allows Heidelberg service technicians to analyze and eliminate possible faults efficiently.

To be able to use the Remote Service, the Suprasetter A52/A74/A75 is connected to your inhouse network during installation by Heidelberg service technicians. This network requires access to the Internet that is used for the Remote Service.

Permission

You can select the following different permission types for Heidelberg Service in this group:

  • Remote Access: By agreeing to it, you permit Heidelberg Service interactive access to your Suprasetter A52/A74/A75.
  • Service Messages: No function at present
  • File transfer: You permit that files will be transferred in the background if a service technicians requests them. No connection is established if this function is not selected.

The permission can be changed at any time as required. Several permissions can also be selected at the same time.
