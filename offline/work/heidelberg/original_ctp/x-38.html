Operating Mode

In this tab, you can change the operating mode for viewing and changing parameters by entering a password.

The operating mode affects which parameters you can view and/or edit in the "Parameter Editor" tab, see Parameter Editor (1).

Operating Mode

The operating mode is changed by selecting a mode and entering the appropriate password.

User mode

Operating mode for normal recorder operation. A password need not be entered.

Service mode

This mode is intended for service technicians and can only be accessed by entering a password. Additional parameters which can be edited by service personnel can be seen.

Research and Development mode

The R&D mode is accessed by entering a password and is intended for development personnel.

Apply

The operating mode is changed by clicking "Apply".
