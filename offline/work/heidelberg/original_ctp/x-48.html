Backup

You can save the machine configuration in this tab and restore it after a software update.

Save Configuration

This function makes sure that you can restore all the recorder data after a software update. You must save the machine configuration before a software update. The recorder configuration files are loaded on the PC. Save Configuration can only be performed in the READY and WAIT recorder states. The current configuration is saved by clicking "Apply".

Restore Configuration

This function must be applied following a software update. It restores the configuration of the recorder as it existed before the software update. When this function is selected, a selection box appears allowing to define whether the configuration stored on the PC or the existing recorder configuration is to be restored. The files may only be selected by service personnel and a selection is only necessary if the data carrier in the recorder has been formatted or if the complete main board of the recorder has been replaced due to a defect. You can only restore the configuration with "Apply" if the recorder status is ERROR or WAIT.

Set to Factory Default Values

Click "Apply" to reset the recorder to the configuration it had on leaving the factory.

Note: All customer-specific settings are deleted. You can only reset the configuration in the ERROR and WAIT recorder states.
