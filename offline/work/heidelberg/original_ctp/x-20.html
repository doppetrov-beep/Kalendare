Material Wizard (9) Quality Test

In this tab, you can start a quality test to check whether the tests that you ran and the settings give you a result you are satisfied with. A test page is output that you can use to check the quality of imaging. In addition, you can measure and optimize alignment of imaging to the punches.

For imaging and evaluation of the quality test, see Imaging of the quality test and Evaluation of the Quality Test.

Material Name

This displays the name of the material that you will run the quality test on. The material name was taken from the "Material Wizard (3)" tab.

Align imaging to punches

To measure distances 1, 2 and 4, please use a microscope with hundredfold magnification.

If imaging is aligned optimally, half of the lines for distances 1, 2 and 4 are cut off by the punches, i.e. the lines still have a thickness of 50 µm at the punch.

Lenticular Imaging

Alignment of the imaging position to the punches is reset to the original values if you selected lenticular imaging. Imaging is then without alignment.

The imaging position is aligned to the punches again when you deselect lenticular imaging.


Distance 1

This is where you enter the value measured for distance 1.

Distance 1: Punch edge to top edge of the horizontal line of the semicircular punches.

Distance 2

This is where you enter the value measured for distance 2.

Distance 2: Punch edge to top edge of the horizontal line of the square punches.

Distance 3

In this box, select the punch that is built into your device.

Distance 3: Center line of the semicircular punch to the center line of the square punch.

Distance 4

This is where you enter the value measured for distance 4.

Distance 4: Left punch edge to left outer edge of the vertical line of the semicircular punches.

Current Values

This displays the current values after you click "Calculate".

Reset

Clicking this icon resets the current values to zero.

Test Selection

This is where you select whether you want to run the quality test for high-resolution material (e.g. for imaging with a satin screen) or material with a lower resolution (for standard screens).

Start quality test

Click this button to start the quality test.

Cancel quality test

Click this button to cancel the quality test. The plate is transported out of the device.

Calculate

Click "Calculate" to calculate the current values for alignment of the imaging position based on the measured values and to enter them in "Rotation", "Fast Scan" and "Slow Scan".

Apply

Click "Apply" to send the current values to the recorder and use them for the imaging runs that will follow.

Close

Click "Close" to go back to "Material Wizard (1)".

Back

Click "Back" to go back to "Material Wizard (10)".
