Material Wizard (4) Punch Mode

In this tab, you can define a default punch combination for the material by selecting single punches and select the punch mode.

Material Name

This displays the name of the material to which you will assign the punch scheme. The material name was taken from the "Material Wizard (3)" tab.

Punch Mode

Always use front-end punch settings

The punch settings of the front-end device are always used even if the recorder has punch settings for the current material.

Use punch settings from recorder if none set by front end

The punch settings of the recorder are only used if the front-end device doesn't have punch settings for the current material.

Always use recorder punch settings

The punch settings of the recorder are always used even if the front-end device has punch settings for the current material.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Close

Click "Close" to go back to "Material Wizard (1)".

Back

Click "Back" to go back to "Material Wizard (3)".

Continue

Click "Next" to open "Material Wizard (5)".
