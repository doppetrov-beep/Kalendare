Material Wizard (6) Focus Evaluation

You can enter the values determined from the focus test in this tab.

Evaluation of the Focus Test, see Evaluation of the Focus Test

Material Name

This displays the name of the material that you used for the focus test. The material name was taken from the "Material Wizard (3)" tab.

A

In this box, enter the number of the test strip that the focus test determined as the correct one for the laser module.

Current focus

This displays the currently applicable focus value.

Calculate

This button is enabled if box A is filled out. Click "Calculate" to calculate the new current focus value.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Close

Click "Close" to go back to "Material Wizard (1)". The current focus value will be used.

Back

Click "Back" to go back to "Material Wizard (5)". The current focus value will be used.

Next

Click "Next" to open "Material Wizard (7)". The current focus value will be used.
