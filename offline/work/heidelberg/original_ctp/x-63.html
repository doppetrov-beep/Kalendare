Operating Counters

This tab displays the various operating counters with their current readings. There are two types of operating counters. One type remains valid until reset to "0" with the Reset button and the other always remains valid.

Counters in the recorder:

  • Material Counter: Indicates the material consumption in m2 since the last reset.
  • Plate counter: Counts the number of plates exposed since the last reset.
  • Exposing Counter: Counts the number of exposed areas.


All three counters can be reset to "0" separately or together by clicking the appropriate button on the right-hand side.

The following parameters are ones which are invariably valid and cannot be reset:

  • Sum of Material Used: Indicates the amount of material used over the entire service life of the unit in m2.
  • Total plate count: Counts the number of plates exposed during the entire service life of the device.
  • Sum of All Exposures: Counts the number of areas exposed over the entire service life of the device.
  • Sum of All Punches: Counts the number of punch actions over the entire service life of the device.
  • Sum of Power On Time: Counts the hours of operation over the entire service life of the unit.
  • Sum of Exposure Time: Counts the time during which the recorder carried out an exposure over the entire service life of the device.
Print

Clicking "Print" prints the operating counters currently shown. The print window of the configured printer appears.

Log File

This tab displays a log file in which all recorder events are recorded. A log file is created and saved each day for each device. The log file can be viewed, sent as an attachment via e-mail or printed.

Summary

If you enable this option, a summary of the log file will be created in addition to the log file. This summary displays the total number of errors, error frequency, etc.

If "Summary" is enabled, a window displays after you click "View", "Print", "Send" or "Save as". In this window, you can merge the log files of the preceding days (max. 20 days) to form one log file.

If "Summary" is not enabled, a window displays after you click "Send" or "Save as". In this window, you can merge the log files of the preceding days (no time limit) to form one log file. To send the log file by e-mail, note that the log file may not be bigger than the max. size of an e-mail attachment.

Options
  • Display User Text

The user error texts are displayed.

  • Display R&D Text

The research and development error texts are displayed.

  • Further Info

Other details from the log file are compiled in a list and displayed.

View

Clicking "View" loads the current recorder log file to the GUI computer and displays it. See also the section Summary.

Print

Clicking "Print" prints the summary of the log file. The print window of the configured printer appears. See also the section Summary.

Sending...

Clicking "Sending..." loads the current log file or the summary from the recorder to the GUI computer. A dialog appears where you can enter an e-mail address to which the log file or the summary will be sent and an address of who sent the e-mail. A valid e-mail address must be entered in both these boxes.

Either the summary or the log file is sent, depending on whether "Summary" is enabled or disabled. See also the section Summary.

An appropriate message displays if a SMTP host is not entered. When you confirm this message with "OK", a line for entering the SMTP host appears in the tab.

Save As...

Click "Save As" to display a dialog for saving the log file. You can store the log file within the directory structure on your PC. See also the section Summary.

Measured Data

This tab shows the measured values in the laser carriage and the backplane and of the dew point.

An appropriate message displays if the measured data exceed the working range.

Laser Diodes

This tab displays the laser diodes of the laser module as lines in the imaging area.

Green line = laser diode is ok.

Red line = laser diode is defective.
