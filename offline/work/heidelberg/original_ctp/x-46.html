Software Update

The current software versions for the various recorder components are displayed in this tab. This tab can also be used for a software update.

Container Version

Here you can select the container version if you wish to perform an update. Make sure beforehand that the container version selected matches the recorder hardware. The entire recorder hardware (optic head) must be connected before an update is possible.

The container software contains all software components required for operating the recorder (recorder firmware, optic head software, etc.).

Apply

Click "Apply" to update the selected software after you confirm a prompt. The update can be followed in a progress bar in a dialog box. You may not switch off the recorder while the update is running. Downloading of the software can be canceled. The subsequent update of the recorder program must not be interrupted.
