System Configuration Tab

OLP at Recorder

The online processor connected to the recorder is selected in this box and on which side the online processor is installed.

Conveyor at Recorder

The conveyor connected to the recorder is selected in this box and on which side the online processor is installed.

Loader

This is where you set whether or not a loader is connected.

New Configuration

System Configuration

The configuration of the Heidelberg products creates a configuration number that is shown in this box.

System configuration ext.

The configuration defined creates an extended configuration number that is shown in this box.

Machine Type

This shows the machine type that you set in the preceding tab.

Apply

After you enter a password and confirm it, the configuration number and machine type are sent to the recorder when you click "Apply".

Next

Click "Next" to display the "System Configuration" tab. This button is only enabled in the "Machine Type" tab.

Back

Click "Back" to go back to the "Machine Type" tab. This button is only enabled in the "System Configuration" tab.
