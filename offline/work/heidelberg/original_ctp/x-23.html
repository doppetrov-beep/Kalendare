Focus Test

The correct focus is determined here. The laser power must be lowered before starting the focus test so that it is possible to evaluate the test pattern.
Recommended value: Power from material release list -30%

Imaging of the Focus Test

The following values are set in the Focus Test tab:

  • Focus range: suggested by the Material Wizard if the correct plate thickness was set.
  • Current focus: suggested by the Material Wizard.
  • Focus test power: Power from material release list -30%

Start the focus test by clicking the "Start focus test" button.

Evaluation of the Focus Test

Only vertical 1-pixel lines are evaluated. These will be evaluated either visually or using the densitometer. With positive plates, the strip with the best focus has the lowest density, with negative plates the strip with the best focus has the highest density.

Enter the numbers of the defined test strips in boxes "A - F" in the "Focus Test Evaluation" tab and click "Calculate". The new current focus value is calculated and shown in the "Current focus" box.

Evaluation for greatly deviating laser modules

Proceed as follows if the Material Wizard rejects your input because the focus values of the separate modules differ too greatly:

Determine the two modules with the lowest and the highest focus value. Obtain the focus mean value of these two modules. Type this focus value in the "Current focus" box and click the "Apply" button to confirm.

Example:

Focus range: 200 - 400

Current focus: 300

Focus test power: 60

Determined focus values of modules:

A = 6; B = 4; C = 6; D = 7; E = 6; F = 6

In this case the Material Wizard will reject calculation because the maximum focus value difference of the modules is too great.

The module with the lowest focus value is module B with a value of 4, equaling a focus of 260.

The module with the highest focus value is module D with a value of 7, equaling a focus of 320.

The focus average is (260+320)/2 = 290.

Type the value of 290 into the "Current focus" box and click "Apply" to accept.
