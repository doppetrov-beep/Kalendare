Material Wizard (5) Focus Test

In this tab, you can set the parameters for the focus test and start the focus test run.

Imaging of the Focus Test, see Imaging of the Focus Test

Material Name

This displays the name of the material that you will run the focus test on. The material name was taken from the "Material Wizard (3)" tab.

Focus range

The focus range is ± 100 µm of the "Current focus". It is calculated from the width and number of test strips and the imaging range of a laser module.

Current focus

This displays the currently applicable focus value.

Focus test power

The focus test power is approx. half the laser module power that is determined during the initial installation at the factory.

Start focus test

Click this button to start the focus test.

Cancel focus test

Click this button to cancel the focus test. The plate is transported out of the device.

Calculate

This button is enabled if the "Current focus" was changed manually. Click "Calculate" to calculate new start and end values (Focus range from - to) for the focus test.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Close

Click "Close" to go back to "Material Wizard (1)". The values of the focus range, the current focus and the focus test power are used. These values are not used if a test is currently running.

Back

Click "Back" to go back to "Material Wizard (4)". The values of the focus range, the current focus and the focus test power are used. These values are not used if a test is currently running.

Next

Click "Next" to open "Material Wizard (6)". The values of the focus range, the current focus and the focus test power are used. These values are not used if a test is currently running.
