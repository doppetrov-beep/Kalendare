Material Wizard (7) Power Test

In this tab, you can set the parameters for the power test and start the power test run.

The power test determines the power that is required to produce the clear point for the plate.

Imaging of the Power Test, see Imaging of the Power Test

Material Name

This displays the name of the material that you will run the power test on. The material name was taken from the "Material Wizard (3)" tab.

Power range

The power range is calculated from the smallest maximum power value of the modules that are used.

Start power test

Click this button to start the power test.

Cancel power test

Click this button to cancel the power test. The plate is transported out of the device.

Calculate

Click "Calculate" to calculate the power range again. The calculation is based on the smallest maximum power value of the modules that are used.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Close

Click "Close" to go back to "Material Wizard (1)". The current power range will be used.

Back

Click "Back" to go back to "Material Wizard (6)". The current power range will be used.

Next

Click "Next" to open "Material Wizard (8)". The current power range will be used.
