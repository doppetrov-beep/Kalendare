Miscellaneous

This tab allows you to:

  • set the language for the user interface dialog,
  • display the material demand table from the main view in a separate large window,

Language

The list box contains a list of all the languages that can be currently set.

You can add another language to the user interface. The /package/properties/ directory in the user interface installation directory contains the MessagesBundle.properties. file. This file contains the English translation of all texts displayed on the user interface. These texts (on the right-hand side of the equal sign) must be translated into the desired language; when doing so, attention must be paid that there are no blanks behind the text.
You must now save the translated MessagesBundle.properties file under a new name. For example, if the language translated is French, the name of the file is MessagesBundle_fr.properties.
The new file must also indicate if a language is specific to a country, for example, MessagesBundle_en_US.properties (en = English, US = USA).

Material demand window

The material demand table from the main view appears in a separate large window if this box is selected.

Advanced User Mode

The "Load Material" button (see the section Load material) in the vertical menu bar is enabled when you select the advanced user mode. This lets you load a plate without any query about loading a plate for imaging.

Feedback Functionality

If "Feedback Functionality" is checked, a window displays when you switch off the recorder from the user interface. You can enter how satisfied you are with the productivity of the device in this window. In Remote Service, this rating is sent with other parameters to your service support.
