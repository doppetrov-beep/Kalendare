Service Book

The Service Book contains parameter details about the software and hardware, which servicing was done and by whom, why servicing was necessary and other notes. You can print and save this Service Book. The Service Book is saved as a PDF file to the following path:

C:\Programs\Heidelberg\CTP User Interface\package\files\logfiles\ServiceBook

Note: The Service Book is saved in English only. For that reason, all entries should be in English.

Open/Close the Parameter Information View

A section with parameter details about the software and hardware opens or closes when you click this button.

Maintenance

This is where the service technician marks which maintenance work he/she did.

Service Partner

The service technician enters his/her name in this box.

Service Issue

The service technician enters the reason for the service call in this box.

Notes

The service technician can write other notes about the service call in this box.
