Timer

You can set the timer for automatic power-up of the recorder in this tab. This lets you switch on the recorder in time before a shift begins.

Recorder Timer

PC Time

This displays the date and time that are set on the PC on which the GUI software of the recorder is installed.

Switch on Timer

You can define settings for the automatic power-up if you selected this function.

Schedule

This is where you can set whether the recorder will be switched on once, daily or on certain weekdays.

Start Time

You can set the start time by overwriting it or by clicking the arrow keys.

Schedule Once

This option only appears if you selected "Once" for "Schedule".

You can set the date by overwriting it, by clicking the arrow keys or by clicking the calendar.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Cancel

Your last inputs are undone by clicking "Cancel" unless the "Apply" button was clicked.
