Horizontal Toolbar

Device

When you click this icon, you can select functions for the configuration of your devices in the vertical menu bar, for example, plate setup, signal settings, language selection, material settings and check of the online processor data.

Job list

Click this icon to display the Job List tab. The job list shows all the jobs that were sent from the front-end device to the recorder for processing.

Service

When you click this icon, you can select functions for service settings in the vertical menu bar, for example, select an operating mode, define ports, set system configurations and parameters, update software, etc.

Heidelberg Remote Service (HeiRes)

When you click this icon, you can select Remote Service functions in the vertical menu bar.

Help

Clicking this icon displays a help text for the currently open dialog.
