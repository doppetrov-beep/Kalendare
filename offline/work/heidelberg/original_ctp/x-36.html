Job List

This tab shows all the jobs that were sent from the front-end device to the recorder for processing.

Job name

The job name is displayed in this column. The job name is taken from the connected front-end device.

Time

This shows the time the job was entered in the list for processing.

Job ID

The job ID is displayed in this column. The ID is taken from MetaShooter.

Size

This shows the plate size for this job.

Status

The present processing status of the job is shown in this column.
