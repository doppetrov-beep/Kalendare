E-mail

In this tab, you can configure whether or not an e-mail will be sent to a computer or a mobile phone and if so for what type of message.

Message

  • Send error message by E-Mail to mobile phone: The number of the message and the "Subject of Mail" are sent to a mobile phone when this option is enabled. The user of the mobile phone who is to receive the message must make sure that the e-mail function is not locked.
  • Send error message by E-Mail to computer: The number of the message and the entire message text are sent to a valid e-mail address when this option is enabled.

Send Message at

This is where you check when a message will be sent. You can enter a different address for every type of message.

  • Error: If this option is checked, a message is sent every time an error occurs.
  • Operation required: A message is always sent whenever user intervention is necessary (e.g. a printing plate must be loaded).
  • Info: A message is always sent announcing a problem that the user must remedy later.
  • Service Info: A message is always sent announcing a problem that the service technicians must remedy later.
  • To: A valid e-mail address (without blanks) to which the message will be sent must be entered in this text box. You can enter several addresses, each separated by a semicolon.

Append log file

The "Append log file" option is enabled when the "Error" option is checked and an e-mail message is to be sent to a computer. The recorder log file is appended to every mail sent when this box is checked.

Use the same Address for all message classes

If this option is checked, the same address is used for all the message classes.

Subject of Mail

In both send options, optional text (24 characters) can be added, e.g. the serial number of the recorder that also appears in the subject heading of the mail.

From:

A valid e-mail address to which a mail server message will be sent if the message cannot be delivered must be entered in this text box.

Authentication Method

If you need to send an e-mail, you must enter the user name and password in these boxes. These must be the ones that you use to log in to your e-mail system.

  • No authentication

- In this case, no authentication is required and the boxes are dimmed.

  • Secure password

- The password is sent encoded.

  • Send unencrypted password

- The password is sent unencrypted.

User Name

Enter a valid e-mail address in this box.

Password

This is where you enter the password for the e-mail address in "User Name".

Connection Security

Select the connection security you want.

The following options are available:

  • None
  • SSL/TLS
  • STARTTLS

Note: You may have to contact your network administrator.

Check Server Certificate

The "Server Certificate" is checked when you select this option.

Test E-Mail

An e-mail is sent to the e-mail address you entered in "User Name" when you click "Test E-Mail". A confirmation displays if the address is correct, if not an error message appears.

Apply

The settings are saved when you click "Apply".

Cancel

Your last inputs are undone by clicking "Cancel" unless the "Apply" button was clicked.

SMTP Host

This box only displays if an e-mail is to be sent but no host address was entered in "SMTP Host" in the "Main Settings" tab. An appropriate error message displays. Then enter the host address, to which your e-mail system is connected. You may have to contact your network administrator to obtain this host address.
