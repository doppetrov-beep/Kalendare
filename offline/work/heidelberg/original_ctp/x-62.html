Setting the Laser Modules

The laser modules must always be set if new laser modules are used or if the results of the quality test make this necessary.

Note: A microscope with hundredfold magnification is required for evaluation of the test.

1. Click "Device" in the horizontal toolbar of the Suprasetter A52/A74/A75 GUI.

2. Select "Configuration" in the vertical menu bar.

3. Select the "System Wizard" tab. System Wizard (1) displays.

4. Select the material that you want to set up the machine with.

5. Click "Next". System Wizard (2) "Slope Correction" displays.

6. Enter the slope test range or use the default range.

7. Insert a plate into the Suprasetter A52/A74/A75.

8. Start the module slope test by clicking the "Start module slope test" button.

The module slope test is run.

9. Develop the printing plate.

10. For each laser module, determine the test strip that shows a smooth line.

11. Click "Next". System Wizard (3) "Evaluation of Slope Correction" displays.

12. Enter the numbers of the defined test strips in boxes "A - F" and click "Calculate". The module slope is calculated and shown in "Module: A" to "Module: F".

13. Click "Apply". The set data are sent to the recorder and activated.

14. Click "Next". System Wizard (4) "Reference Temperature" displays.

15. Click "Set new reference temperature". The reference temperature of the laser modules is determined, sent to the recorder and enabled.

16. Click "Next". System Wizard (5) "Reference Distance" displays.

17. Click "Start reference distance test of the laser modules". The reference distance between the laser modules is determined, sent to the recorder and enabled.
