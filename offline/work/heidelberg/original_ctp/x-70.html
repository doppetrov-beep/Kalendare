Send Mail

You can send an e-mail in this tab. The contents of the e-mail depend on the menu that opened the "Send Mail" dialog, e.g. "Log File" (the complete log file), "Parameter Editor (1)" (the selected parameters) or "Backup" (the configuration data).

To:

A valid e-mail address (without blanks) to which the message will be sent must be entered in this text box. You can enter several addresses, each separated by a semicolon.

CC:

A valid e-mail address (without blanks) to which a copy of the message is to be sent must be entered in this box. You can enter several addresses, each separated by a semicolon.

From:

A valid e-mail address to which a mail server message is to be sent if the message cannot be delivered must be entered in this text field.

Send

The e-mail is sent by clicking "Send". If the SMTP host address to which the e-mail system is connected is not yet entered in the "Main Settings" tab, a text box appears where you can define this.

Close

Click "Close" to close the dialog without sending any mail.
