Instructions for Testing Printing Plates

Preparations

The following measuring instruments are required to set the imaging parameters, focus and light values correctly:

  • Microscope, magnification 100x, e.g. Peak pocket microscope 100x (is mandatory)
  • Acetone for testing positive plates for absence of hairlines
  • Reflection densitometer for laser power adjustment for negative plates

When testing the printing plates, fresh developer should be used at all times. Exchange the developer fluid one day before testing if possible. This is to ensure the developer fluid loses some of its aggressiveness.

The printing plate must be set up in the Suprasetter user interface (see Material Selection.

In order to test the printing plate on the Suprasetter and the processor, the following steps are necessary for all plate types used.

  • Focus test
  • Power test
  • Gradient test (not always required)
  • Balance test (possibly in several iterations)
  • Quality test
