System Wizard (5) Reference Distance

You must determine the reference distance of the laser module in this tab. The other tests are based on this reference distance.

The reference distance may only be determined when the Suprasetter A52/A74/A75 has reached its operating temperature. You cannot see a thermometer and the Suprasetter is red in the main view if the operating temperature is not yet reached. A message is also displayed.

Note: Before you determine the reference distance, the reference temperature is automatically checked and, if necessary, entered as the current reference temperature in the "System Wizard (4) Reference Temperature".

Start reference distance test of the laser module

The reference distance is determined, sent to the recorder and enabled when you click this button.
