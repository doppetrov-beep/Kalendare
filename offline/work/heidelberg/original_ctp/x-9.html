Status Area

This area displays various device details and states, e.g. device name, device status, job name, etc.

Switch Off Recorder

A recorder shutdown routine starts when you click this button and confirm the subsequent message displayed , i.e. the software is set to a defined switch-off state.

Recorder Error Messages

If a fault occurs in the device, click this button to display a window where you can find more details about the error and what steps are to be taken to eliminate it.

Start safety loop test

Testing of the safety loop starts after you click this button and confirm again.

Note: During the test no imaging jobs may be processed!

This displays the interval until the next regular safety loop test.

Device Name

This column displays the product name of the device to which the graphical user interface is connected.

Device State

The current device state is displayed in this column:

OFFLINE

The workstation on which the GUI is installed is not connected to the device.

ERROR

There is a fault in the device.

USERSTATE

Work is interrupted because, for example, the tray is empty (only if the Auto Plate Loader is used) or the online processor is not ready.

READY (WAIT, PREPARE)

The device is booted and ready to load and image plates.

BOOT

Booting or an update is running.

BOOTLOADER

Only important for service technicians and R & D: The GUI is communicating with the Bootloader.

Info

Plate status

The plate can have the following states:

OFFLINE

The workstation on which the GUI is installed is not connected to the device.

ACTIVE

At least one plate is being processed in the device.

INACTIVE

There is no plate in the device.

Switch status symbols

The following switch symbols can appear:

Keyswitch

The key-operated switch was pressed for service work.

Warning: The key-operated switch must only be operated by service personnel and not by the user. The safety loop is closed via the key-operated switch. As a result, the laser cannot be activated. Depending on the device, the user is now in danger of being crushed by the cassette drive, table movements, drum rotation (fast scan), the imaging carriage (slow scan) or other mechanical motions or by being fatally injured by an electric shock.

Emergency Switch

One of the emergency switches on the Suprasetter A52/A74/A75 was pressed. This stops all mechanical motions in the Suprasetter A52/A74/A75.
