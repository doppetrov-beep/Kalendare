Material Wizard (3) Material Parameters

You can set and save the new material parameters in this tab.

Material Name

Name of corresponding material, e. g.:
KodakElektraExcel790x1030.

Width

Enter the width of the material used.

Length

Enter the length of material used.

Thickness

Enter the material thickness.

Polarity

Select positive or negative exposure.

OLP Program No.

Enter the number of the online processor program that is to be used for developing the plate. The programs differ for example in different developing times and developer temperatures.

Sensitivity

This is where you enter the sensitivity of the material. You will find details about the sensitivity on the material packaging.

Speed

This is where you enter the speed of the imaging drum. The speed depends on the plate you selected.

Enable extraction for this material

Select this function if you wish to switch on the suction that sucks off the burnout that is produced when imaging the plate.

Run tests for non-chemical plates

Tests for chemical-free plates are used to test the printing plates when you select this function.

Plate Separation Mode

If problems occur in the Auto Plate Loader when plates are being separated, error messages display, requesting you to change the plate separation mode. By default, mode 1 is set. The higher modes change the routines in the Auto Plate Loader in such a way that makes plate separation more reliable but at the same time also reduces the maximum processing speed.

You must try out for yourself which plate separation mode is best suited for your plate.

Unload material

Manual Side

The imaged plate exits to the insertion table if this function is selected.

Automatic Processing

The imaged plate is conveyed automatically to the connected processor via the conveyor if this function is selected.

Stop on Conveyor

The imaged plate remains on the conveyor and can be removed manually for further processing if this function is selected.

Apply

The settings are sent to the recorder and enabled when you click "Apply".

Close

Click "Close" to go back to "Material Wizard (1)".

Back

Click "Back" to go back to "Material Wizard (2)", for example, to select a different material from the list.

Continue

Click "Next" to open "Material Wizard (4)".
