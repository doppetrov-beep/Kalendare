Connection name

Type a name for the connection you will set below.

Connection

You select the physical connection of the user interface to the recorder in this list box.

  • Serial Com Port: Select this type of connection if the user interface is connected to the recorder by means of the serial port of the PC.
  • Ethernet: Select this type of connection if the user interface is connected to the recorder by means of the Ethernet port of the PC.

Serial Com Port

You can enter the port number in this box if Serial Com Port was selected as the type of connection.

Ethernet

The Ethernet address is set by default and may not be changed if your computer is connected directly to the recorder. If your computer will be connected to the recorder through your inhouse network, you must enter the Ethernet address that was assigned to the recorder by the network administrator.

SMTP Host

Enter the host address, to which your e-mail system is connected. This address is required if parameters, the logfile or error messages are sent as an e-mail from this user interface to a computer or a mobile phone. You may have to contact your network administrator to obtain this host address.

Apply

The settings are saved by clicking "Apply". The user interface must be closed and restarted before the selection becomes effective.

Cancel

Your last inputs are undone by clicking "Cancel" unless the "Apply" button was clicked.

Delete

Click "Delete" to delete the connection set in "Connection name". You cannot delete the current connection.
