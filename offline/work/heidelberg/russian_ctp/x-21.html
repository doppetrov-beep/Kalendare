Инструкция по тестированию печатных пластин

Подготовка

Для правильного определения параметров изображения, фокусировки и световых значений требуются следующие измерительные приборы:

  • Микроскоп, увеличение 100x, например. Пиковый карманный микроскоп 100x (обязательно)
  • Ацетон для тестирования положительных пластин на отсутствие волосяных линий
  • Рефлекторный денситометр для регулировки мощности лазера для отрицательных пластин

При тестировании печатных пластин следует всегда использовать свежего разработчика. Обменяйте жидкость разработчика за день до тестирования, если это возможно. Это делается для того, чтобы жидкость разработчика потеряла часть своей агрессивности.

Печатная пластина должна быть установлена в пользовательском интерфейсе Suprasetter (см. Выбор материала.

Для того, чтобы протестировать печатную пластину на Suprasetter и процессоре, необходимы следующие шаги для всех используемых типов пластин.

  • Фокус-тест
  • Испытание на мощность
  • Градиентный тест (не всегда требуется)
  • Балансовый тест (возможно, в нескольких итерациях)
  • Тест качества
