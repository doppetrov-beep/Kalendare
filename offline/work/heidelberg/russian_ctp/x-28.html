Прочие

Эта вкладка позволяет вам:

  • установить язык для диалога пользовательского интерфейса,
  • отображать таблицу спроса на материалы с основного вида в отдельном большом окне;

Язык языка

Список содержит список всех языков, которые могут быть установлены в настоящее время.

Вы можете добавить другой язык в пользовательский интерфейс. Каталог /package/properties/ в каталоге установки пользовательского интерфейса содержит файл MessagesBundle.properties. Этот файл содержит английский перевод всех текстов, отображаемых в пользовательском интерфейсе. Эти тексты (с правой стороны знака равенства) должны быть переведены на нужный язык; при этом следует обратить внимание на то, что за текстом нет пробелов.
Теперь вы должны сохранить переведенный файл MessagesBundle.properties под новым именем. Например, если переведенный язык является французским, имя файла - MessagesBundle_fr.properties.
В новом файле также должно быть указано, является ли язык специфическим для страны, например, MessagesBundle_en_US.properties (en = English, US = USA).

Окно спроса на материалы

Таблица спроса на материал с основного вида появляется в отдельном большом окне, если выбрана эта коробка.

Расширенный пользовательский режим

Кнопка «Загрузка» (см. раздел) Загрузочный материал) в вертикальной строке меню включен при выборе расширенного пользовательского режима. Это позволяет загружать пластину без какого-либо запроса о загрузке пластины для визуализации.

Функциональность обратной связи

Если проверяется «Функциональность обратной связи», окно отображается при выключении регистратора из пользовательского интерфейса. Вы можете указать, насколько вы удовлетворены производительностью устройства в этом окне. В удаленном сервисе этот рейтинг отправляется с другими параметрами в вашу службу поддержки.
