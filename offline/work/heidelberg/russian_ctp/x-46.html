Обновление программного обеспечения

Текущие версии программного обеспечения для различных компонентов регистратора отображаются в этой вкладке. Эта вкладка также может использоваться для обновления программного обеспечения.

Версия контейнера

Здесь вы можете выбрать версию контейнера, если вы хотите выполнить обновление. Заранее убедитесь, что выбранная версия контейнера соответствует аппаратному обеспечению регистратора. Все аппаратное обеспечение регистратора (оптическая головка) должно быть подключено до обновления.

Программное обеспечение контейнера содержит все программные компоненты, необходимые для работы регистратора (программное обеспечение для записи, программное обеспечение для оптической головки и т. Д.).

Применять

Нажмите «Применить», чтобы обновить выбранное программное обеспечение после подтверждения запроса. За обновлением можно следить в строке прогресса в диалоговом окне. Вы не можете выключить диктофон во время работы обновления. Загрузка программного обеспечения может быть отменена. Последующее обновление программы записи не должно прерываться.
