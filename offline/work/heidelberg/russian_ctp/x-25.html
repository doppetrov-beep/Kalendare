Тест качества

Этот тест проверяет баланс мощности отдельных лазерных модулей и при необходимости сбрасывает мощность в рабочую точку.

Тест качества используется для окончательной оценки параметров Suprasetter и качества визуализации.

Используйте экран, соответствующий потенциальным ограничениям для тестирования качества.

Например, пластина AGFA Azura была выпущена только для экрана с разрешением 80 строк / см. В этом случае выберите опцию «Тест качества для материала с низким разрешением» во вкладке «Тест качества» (IS Classic, 100 л/см).

Выберите опцию «Тест качества для материалов с высоким разрешением» для пластин с высоким разрешением, таких как Kodak DITP Gold, поскольку в противном случае оценка качества для FM-экранов недостаточна.

Тест на качество для положительных пластин

Изображение теста качества

Начните тестирование качества, нажав кнопку «Начать тестирование качества».

Оценка теста качества

Для оценки качества важно перпендикулярно просматривать пластину, поскольку наклонный угол обзора может привести к ложному впечатлению яркости.

По той же причине вы должны выбрать освещение, которое не позволяет отражениям на поверхности пластины достичь глаза зрителя.

Мы рекомендуем расстояние обзора не менее 30 см.

Проверка рабочей точки

Чтобы проверить рабочую точку, оцените весы для баланса мощности, отображаемые каждым модулем. По сравнению с тестом баланса пластырь, где сливаются алмаз и фон, не должен был измениться. В неблагоприятном случае необходимо пропорционально адаптировать мощность для всех модулей.

Как правило, вам придется снизить мощность. Вместо того, чтобы уменьшать мощность, вы также можете пропорционально увеличить скорость (см. пример 7.3 ниже).

Для положительных пластин вы должны, наконец, проверить на вкладке теста качества, если фон пластины в непечатных областях полностью пуст.

Вы можете сделать это с помощью микроскопа. Однако так называемый тест на ацетон является оптимальным. Нанесите каплю ацетона на достаточно большую непечатную область (область выгорания или серая шкала 0% пластырь). Ацетон растворяет остатки покрытия и откладывает их как типичное кольцо по краям диспергирующей капли. Описываемое кольцо может быть слабо видимым. Фон пластины недостаточно чистый, если кольцо, окрашенное как покрытие пластины, хорошо видно.

В этом случае необходимо либо увеличить мощность, либо развитие плиты не оптимально.

Проверка выравнивания модуля

Существует степной серый клин и градационный клин на каждой границе модуля. Не должно быть никакого видимого скачка плотности на границах модуля в любом из серых клиньев. Это относится ко всем тональным уровням; между любыми модулями не должно быть видимого скачка плотности.

Проверка выравнивания геометрического модуля

Серые шкалы для проверки качества используются для проверки геометрического выравнивания диапазонов изображений модулей.

Граница модуля находится примерно в серой шкале середины. В этой области не должно быть видимого, печатного волосяного покрова (темного, окрашенного, как покрытие пластины).

В таком случае вы должны исправить положение модуля справа от границы модуля, на которую вы смотрите.

Увеличить положение на единицу для положительных пластин. Вы также должны увеличить положение на один блок для всех модулей справа от исправленного модуля, поскольку в противном случае ошибка геометрического выравнивания будет смещена в соответствующий соседний модуль справа.

Для отрицательных пластин необходимо свести положения модулей вправо от границы для коррекции одним блоком.

Незначительная яркая, непечатная линия может быть допущена, так как она, вероятно, будет невидимой в печатном продукте.

Тест на качество отрицательных пластин

Чтобы оценить качество теста на отрицательные пластины, он должен быть напечатан в виде доказательства.

Изображение теста качества

Чтобы пробить пластины, сделайте следующие настройки во вкладке «Режим удара» Мастера материалов:

  • «Всегда используйте настройки удара рекордера»
  • Установка пунша, подходящая для доказательной печати.

Начните тестирование качества, нажав кнопку «Начать тестирование качества».

Оценка теста качества

Оценка страницы тестирования качества похожа на положительную таблицу. Невозможно проверить рабочую точку, так как тонкие экраны шкалы проверки мощности страдают от увеличения точек во время печати и не могут быть оценены.

Пример расчета для выравнивания рабочих точек

Установите следующие значения после балансировки мощности:

Модуль A = 83,4; B = 91,4; C = 89,0; D = 87,4; E = 87,4; F = 87,4

Скорость: 235rpm

Предыдущим поединком был патч 9

После баланса питания, патч матча - это патч 8.

Из теста на мощность вы можете установить, что изменение одним патчем вызвано изменением мощности ка. 4 мВт.

Есть два способа восстановить прежнюю рабочую точку:

1. Пропорциональное снижение мощности:

Средняя мощность модуля PM составляет

PM = (PA+PB+PC+PD+PE+PF)/6

ТЧ = (83,4+91,4+89,0+87,4+87,4+87,4)/6

ТЧ = 87,67 мВт

ΔP = 4 мВт

X = (PM - ΔP)/PM

X = (87,67 мВт - 4 мВт) / 87,67 мВт

X = 0.954

Pnew = Pold * X

PAnew = PAold * X = 83,4 мВт * 0,954 = 79,6 мВт

PBnew = PBold * X = 91,4 мВт * 0,954 = 87,2 мВт

PCnew = PCold * X = 89,0 мВт * 0,954 = 84,9 мВт

PDnew = PDold * X = 87,4 мВт * 0,954 = 83,4 мВт

PEnew = PEold * X = 87,4 мВт * 0,954 = 83,4 мВт

PFnew = PFold * X = 87,4 мВт * 0,954 = 83,4 мВт

2. Пропорциональное увеличение скорости барабана:

Средняя мощность модуля PM составляет

PM = (PA+PB+PC+PD+PE+PF)/6

ТЧ = (83,4+91,4+89,0+87,4+87,4+87,4)/6

ТЧ = 87,67 мВт

ΔP = 4 мВт

X = (PM - ΔP)/PM

X = (87,67 мВт - 4 мВт) / 87,67 мВт

X = 0.954

Ddrumnew = Ddrumold / X = 235 об/мин / 0.954 = 246 об/мин

Введите новую мощность или новые значения скорости в соответствующих полях в Мастере материалов.

Чтобы проверить новую рабочую точку, вы должны получить изображение теста качества.

Оригинальное название: Align Imaging to the Punches

Этот тест качества также позволяет измерять и оптимизировать выравнивание изображения к ударам.

Продолжайте следующим образом:

1. Измеряйте расстояния 1, 2 и 4 на изображенной пластине с помощью микроскопа со стократным увеличением.


2. Введите значения, измеренные для расстояний, в соответствующие поля во вкладке «Тест качества».

3. Для «Расстояния 3» выберите пунш, встроенный в ваше устройство.

4. Нажмите «Вычислить». Значения, рассчитанные для выравнивания положения изображения к ударам, вводятся в «Текущие значения».

5. Выберите, хотите ли вы запустить тест качества для материала с высоким разрешением или материала с более низким разрешением.

6. Нажмите «Применить». Текущие значения отправляются на устройство экспонирования и используются для выполнения изображений, которые последуют.

7. Начните тестирование качества для установленного материала, нажав кнопку «Начать тестирование качества».

8. Разработайте печатную пластину.

9. Проверьте изображение пластины:

Если изображение выровнено оптимально к ударам, половина линий для расстояний 1, 2 и 4 отрезана ударами, то есть линии все еще имеют толщину 50 мкм при ударе.

Если изображение не выровнено оптимально к ударам, вы должны снова измерить расстояния 1, 2 и 4 и повторить тест.
