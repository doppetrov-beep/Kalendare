Отправить почту

Вы можете отправить электронное письмо на этой вкладке. Содержимое электронной почты зависит от меню, которое открыло диалог «Отправить почту», например. ""Log File"(полный файл журнала), "Редактор параметра (1)"(выбранные параметры) или "Резервное копирование"(конфигурационные данные).

Для:

Действительный адрес электронной почты (без заготовок), на который будет отправлено сообщение, должен быть введен в этот текстовый ящик. Вы можете ввести несколько адресов, каждый из которых разделен полуколоном.

CC:

Действительный адрес электронной почты (без заготовок), на который должна быть отправлена копия сообщения, должен быть введен в этот ящик. Вы можете ввести несколько адресов, каждый из которых разделен полуколоном.

Из:

Действительный адрес электронной почты, на который должно быть отправлено сообщение почтового сервера, если сообщение не может быть доставлено, должен быть введен в это текстовое поле.

Отправить

Электронное письмо отправляется путем нажатия «Отправить». Если адрес хоста SMTP, к которому подключена система электронной почты, еще не введен в "Основные настройки"вкладка, текстовое поле появляется там, где вы можете определить это.

Закрыть

Нажмите «Закрыть», чтобы закрыть диалог без отправки почты.
