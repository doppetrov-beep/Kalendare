Электронная почта

В этой вкладке вы можете настроить, будет ли отправлено электронное письмо на компьютер или мобильный телефон, и если да, то для какого типа сообщения.

Послание

  • Отправьте сообщение об ошибке по электронной почте на мобильный телефон: номер сообщения и «Субъект почты» отправляются на мобильный телефон, когда эта опция включена. Пользователь мобильного телефона, который должен получить сообщение, должен убедиться, что функция электронной почты не заблокирована.
  • Отправьте сообщение об ошибке по электронной почте на компьютер: номер сообщения и весь текст сообщения отправляются на действительный адрес электронной почты, когда эта опция включена.

Отправить сообщение на

Здесь вы проверяете, когда будет отправлено сообщение. Вы можете ввести другой адрес для каждого типа сообщения.

  • Ошибка: если эта опция проверена, сообщение отправляется каждый раз, когда происходит ошибка.
  • Требуемая операция: сообщение всегда отправляется, когда требуется вмешательство пользователя (например, печатная пластина должна быть загружена).
  • Сообщение всегда отправляется, объявляя о проблеме, которую пользователь должен устранить позже.
  • Информация об обслуживании: всегда отправляется сообщение, в котором сообщается о проблеме, которую технические специалисты должны решить позже.
  • Для: Действительный адрес электронной почты (без заготовок), на который будет отправлено сообщение, должен быть введен в этом текстовом поле. Вы можете ввести несколько адресов, каждый из которых разделен полуколоном.

Добавить файл log

Опция «Добавить файл журнала» включается при проверке опции «Ошибка» и отправке сообщения электронной почты на компьютер. Файл журнала регистратора прилагается к каждой почте, отправленной при проверке этого ящика.

Используйте один и тот же адрес для всех классов сообщений

Если эта опция проверена, то для всех классов сообщений используется один и тот же адрес.

Тематика почты

В обоих вариантах отправки может быть добавлен дополнительный текст (24 символа), например, серийный номер регистратора, который также появляется в заголовке темы почты.

Из:

Действительный адрес электронной почты, на который будет отправлено сообщение почтового сервера, если сообщение не может быть доставлено, должен быть введен в этом текстовом поле.

Метод аутентификации

Если вам нужно отправить электронное письмо, вы должны ввести имя пользователя и пароль в этих полях. Это должны быть те, которые вы используете для входа в систему электронной почты.

  • Нет аутентификации

В этом случае аутентификация не требуется, и коробки затемнены.

  • Безопасный пароль

- Пароль отправляется закодированным.

  • Отправить незашифрованный пароль

- Пароль отправляется незашифрованным.

Имя пользователя

Введите действительный адрес электронной почты в этом поле.

Пароль

Здесь вы вводите пароль для адреса электронной почты в «Имя пользователя».

Безопасность подключения

Выберите безопасность соединения, которую вы хотите.

Доступны следующие варианты:

  • Никто.
  • SSL/TLS
  • СТАРТТЛЫ

Примечание: Возможно, вам придется связаться с вашим сетевым администратором.

Проверка серверного сертификата

Сертификат сервера проверяется при выборе этой опции.

Тест E-Mail

Электронное письмо отправляется на адрес электронной почты, который вы ввели в «Имя пользователя», когда вы нажимаете «Проверить электронную почту». Подтверждение отображается, если адрес правильный, если не появляется сообщение об ошибке.

Применять

Настройки сохраняются, когда вы нажимаете «Применить».

отменять

Ваши последние входные данные отменяются, нажав «Отменить», если кнопка «Применить» не была нажата.

SMTP Host

Этот ящик отображается только в том случае, если необходимо отправить электронное письмо, но адрес хоста не был введен в «SMTP Host» во вкладке «Основные настройки». Соответствующее сообщение об ошибке отображается. Затем введите адрес хоста, к которому подключена ваша система электронной почты. Возможно, вам придется связаться с вашим сетевым администратором, чтобы получить этот адрес хоста.
