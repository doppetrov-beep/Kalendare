Фокус-тест

Здесь определяется правильный фокус. Перед началом испытания на фокусировку мощность лазера должна быть снижена, чтобы можно было оценить образец испытания.
Рекомендуемое значение: Мощность из списка высвобождения материала -30%

Изображение теста Focus

Следующие значения установлены во вкладке Focus Test:

  • Диапазон фокусировки: предлагается мастером материала, если установлена правильная толщина пластины.
  • Оригинальное название: The Material Wizard.
  • Тестовая мощность фокусировки: мощность из списка высвобождения материала -30%

Начните тест фокусировки, нажав кнопку «Начать тест фокусировки».

Оценка теста Focus

Оцениваются только вертикальные 1-пиксельные линии. Они будут оцениваться либо визуально, либо с помощью денситометра. С положительными пластинами полоса с лучшим фокусом имеет самую низкую плотность, с отрицательными пластинами полоса с лучшим фокусом имеет самую высокую плотность.

Введите номера определенных тест-полосок в полях «A - F» во вкладке «Оценка результатов испытаний» и нажмите «Вычислить». Новое значение текущего фокуса вычисляется и отображается в поле «Текущий фокус».

Оценка сильно отклоняющихся лазерных модулей

Действуйте следующим образом, если Мастер Материала отклоняет ваш ввод, потому что значения фокусировки отдельных модулей слишком сильно различаются:

Определите два модуля с самым низким и самым высоким значением фокусировки. Получите среднее значение фокуса этих двух модулей. Введите это значение фокусировки в поле «Текущий фокус» и нажмите кнопку «Применить», чтобы подтвердить.

Пример:

Диапазон фокусировки: 200 - 400

Текущий фокус: 300

Испытательная мощность: 60

Определенные значения фокусировки модулей:

A = 6; B = 4; C = 6; D = 7; E = 6; F = 6

В этом случае Material Wizard отклонит вычисления, потому что максимальная разница значений фокусировки модулей слишком велика.

Модуль с наименьшим значением фокусировки представляет собой модуль B со значением 4, равным фокусу 260.

Модуль с наибольшим значением фокусировки является модулем D со значением 7, равным фокусу 320.

Средний фокус (260+320)/2 = 290.

Введите значение 290 в поле «Текущий фокус» и нажмите «Применить», чтобы принять.
