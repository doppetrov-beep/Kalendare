Мастер материалов (6) Оценка фокуса

Вы можете ввести значения, определенные из теста фокусировки в этой вкладке.

Оценка фокус-теста, см. Оценка теста Focus

Материальное имя

Это отображает название материала, который вы использовали для теста фокусировки. Материальное название было взято из вкладки «Материальный волшебник (3)».

A

В этом поле введите номер тест-полоски, которую тест фокусировки определил как правильную для лазерного модуля.

Текущая направленность

Это отображает применимое в настоящее время значение фокусировки.

вычислять

Эта кнопка включена, если коробка А заполнена. Нажмите «Вычислить» для расчета нового текущего значения фокусировки.

Применять

Настройки отправляются на диктофон и включаются при нажатии «Применить».

Закрыть

Нажмите «Близко», чтобы вернуться к «Материальный волшебник (1)». Будет использоваться текущее значение фокуса.

Назад

Нажмите «Назад», чтобы вернуться к «Материальный волшебник (5)». Будет использоваться текущее значение фокуса.

Следующий

Нажмите «Далее», чтобы открыть «Материальный волшебник (7)». Будет использоваться текущее значение фокуса.
