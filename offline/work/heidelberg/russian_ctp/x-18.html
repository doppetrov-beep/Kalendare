Мастер материалов (7) Тест на мощность

В этой вкладке вы можете установить параметры для испытания мощности и запустить тестовый запуск мощности.

Испытание на мощность определяет мощность, необходимую для получения четкой точки для пластины.

Тест на мощность, см. Изображение Power Test

Материальное имя

Это отображает название материала, на котором вы будете запускать тест на мощность. Материальное название было взято из вкладки «Материальный волшебник (3)».

Диапазон мощности

Диапазон мощности рассчитывается из наименьшего максимального значения мощности используемых модулей.

Начать силовой тест

Нажмите эту кнопку, чтобы начать тест питания.

Тест на отмену электроэнергии

Нажмите эту кнопку, чтобы отменить тест питания. Тарелка транспортируется из устройства.

вычислять

Нажмите «Вычислить», чтобы снова вычислить диапазон мощности. Расчет основан на наименьшем максимальном значении мощности используемых модулей.

Применять

Настройки отправляются на диктофон и включаются при нажатии «Применить».

Закрыть

Нажмите «Близко», чтобы вернуться к «Материальный волшебник (1)». Будет использоваться текущий диапазон мощности.

Назад

Нажмите «Назад», чтобы вернуться к «Материальный волшебник (6)». Будет использоваться текущий диапазон мощности.

Следующий

Нажмите «Далее», чтобы открыть «Материальный волшебник (8)». Будет использоваться текущий диапазон мощности.
