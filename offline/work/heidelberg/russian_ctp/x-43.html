Редактор параметра (1)

В этой вкладке вы можете просмотреть все параметры, используемые для работы регистратора. Вы можете ограничить параметры, показанные, выбрав набор данных и назначив атрибут. Некоторые параметры появляются только в том случае, если соответствующий режим работы был установлен во вкладке «Оперирующий режим». Параметры отображаются в таблице, столбцы которой имеют следующее значение:

  • FID: идентификационный номер набора данных
  • PID: идентификационный номер параметра
  • Название: Название параметра
  • Значение: Текущее значение параметра

Выбор набора данных

Один или все наборы данных, параметры которых должны отображаться в таблице, могут быть выбраны в этом списке.

Доступны следующие наборы данных:

  • Все: Если это выбрано, отображаются все параметры из всех пяти наборов данных в таблице.
  • Применение: все параметры, необходимые для разрешения и геометрии для одного процесса экспозиции. Эти параметры действительны только для одного запуска экспозиции.
  • Действие: отображаются все параметры, которые необходимы для сопутствующих действий для процесса воздействия, таких как резка, пробивание и транспортировка материалов. Эти параметры также действительны только для одного запуска экспозиции.
  • Материал: перечислены все параметры, описывающие свойства материала. Они включают, например, геометрию материала, тип материала или данные экспозиции, зависящие от разрешения.
  • Статика: Здесь собраны все специфические для машины параметры, такие как доступные разрешения, данные геометрии или параметры конфигурации.
  • Мера: Здесь собраны все определенные значения. Это значения, которые могут быть изменены (счетчик длины, время) и статические значения (запросы конфигурации, предельные значения), которые определяются машиной и доступны в этом наборе данных.

атрибут

Этот список позволяет ограничить выбор параметров, показанных еще дальше. Доступны следующие атрибуты параметров:

  • Нет: Если это выбрано, все параметры выбранного набора данных отображаются без каких-либо ограничений.
  • Фабрика: отображаются все параметры, которые сохраняются во время действия «Сохранить конфигурацию».
  • Восстановление: отображаются только те параметры, которые перезаписываются новыми значениями после обновления программного обеспечения.
  • Геометрия: Этот атрибут определяет, являются ли показанные параметры параметрами геометрии. Показаны только они.
  • Жизненный период: если выбрано, отображаются все параметры жизни.
  • Нелетучие: если это выбрано, отображаются все нелетучие параметры.
  • Восстановление никогда: эти ценности никогда не восстанавливаются. Они являются лишь временными значениями, определяемыми во время выполнения.

Поиск для

Идентификационный номер параметра может быть введен в левом поле над колонкой PID. Перечислены все параметры, содержащие эту комбинацию чисел. Имя параметра или его часть могут быть введены в правой коробке над колонкой «Имя». Перечислены все параметры, содержащие эту комбинацию символов.

Вы можете искать либо идентификационный номер параметра, либо имя параметра, но не оба одновременно.

Вы можете сортировать параметры, показанные в таблице в порядке восходящего или нисходящего, по их PID или их имени. Для этого щелкните соответствующим заголовком столбца мышью. Порядок сортировки можно изменить, нажав еще раз:

  • Сортировать по восходящему порядку
  • Сортировать в порядке убывания

Редактировать...

Кнопка «Изменить...» может быть использована, если вы выбрали строку в таблице с помощью мыши. Затем появляется диалог, в котором вы можете отредактировать выбранный параметр (см. Редактор параметра (2) вкладка). Некоторые параметры могут быть отредактированы только в том случае, если соответствующий режим работы был установлен в Оперативный режим.. Двойной клик по строке также открывает диалоговое окно для редактирования параметра.

Отправить...

Когда вы нажимаете «Отправить...», все данные параметров в таблице загружаются с регистратора, и появляется диалоговое окно, откуда вы можете отправить параметры по электронной почте.

Сохранить на PC

Когда вы нажимаете «Сохранить», все данные параметров в таблице загружаются с регистратора и сохраняются в файл на компьютере графического интерфейса.

Загрузка...

Кнопка «Загрузка...» открывает диалог, с помощью которого определенный набор данных параметров может быть загружен с жесткого диска или дискеты и отображен в таблице. Эта функция включена только в режиме «Услуга» или «Исследование и разработка».

Применять

Нажмите «Применить», чтобы загрузить набор данных, загруженный заранее на устройство экспонирования, и сохранить его навсегда.

В режиме «Сервис» или «Исследование и разработка» нажатие этой кнопки навсегда сохраняет наборы данных, которые были загружены заранее с жесткого диска или диска с помощью кнопки «Загрузка».
