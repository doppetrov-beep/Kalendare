Sorted and Unsorted Output

You can choose between two output workflows, between a sorted output and an unsorted one.

Note: The choice of a sorted or unsorted output influences your entire output workflow and you should configure it once directly after launching the Prinect Shooter.

Sorted Output

In a sorted output, the job context is kept, i.e. the whole job is always output. This means that all the plates that are part of a job are always processed by Prinect Shooter one after the other in their correct order. In the Prinect Shooter Printmanager, sorted jobs are marked by a blue folder icon, indicating that the plates belong to one job. However, this variant has as its condition that a job cannot be interrupted. For example, the sorted output of a very large job must be completely finished before you can output another job, even just a single plate of it.

Configuration

Prerequisite: The following requirements must be met for a sorted output of your jobs:

  • The Tiff-B jobs must be output by Prinect MetaDimension with the FBDI protocol enabled.

When you configure the Tiff-B Export Engine Manager, you can define in Prinect MetaDimension whether the generated TIFF-B files will be sent to Prinect Shooter with or without a FBDI protocol. To view or configure this setting, open the Tiff-B Export Engine Manager on the Prinect MetaDimension PC and open the output device you want in "Devices". In "FBDI Protocol" in the "Data Output" tab, you can choose between the following options:

    • No FBDI output
    • Supervised FBDI output or
    • Non-supervised FBDI output

For a sorted output, enable either "Supervised FBDI output" or "Non-supervised FBDI output" (you can find more details about these options in the Online Help of the TIFF-B Export Engine Manager).

  • You must have enabled the "Serial, sorted output via FBDI workflow" option in Prinect Shooter.

You can enable this option in the "Administration > Configuration" tab (see also the "Serial, sorted output via FBDI workflow").

When these two requirements are met, jobs are sorted in their correct order when output.

Note: If you want to output single separations ("signatures") again, the sorted output has a slightly different workflow to the unsorted output (see the Reprinting Single Separations).

Reorder sorted output

In a sorted output, you can only rearrange the order of whole jobs. This lets you modify the output order (See Reordering Jobs). You cannot change the order of single separations or "plates".

Unsorted Output

In an unsorted output, the single separations in a job are processed separately as "component jobs". You can interrupt the output of an entire job or you can use the "Reorder" function (see the Reordering Jobs) to change the processing order of single plates in a job (the "component jobs"). This workflow is more flexible than the sorted output, but you must make sure that after imaging the imaged plates are assigned to the correct jobs.

Configuration

Note: The jobs are not sorted when output if one of the following requirements is met:

  • The Tiff-B jobs are output by Prinect MetaDimension without a FBDI protocol.

In the TIFF-B Export Engine Manager, select the output device you want in "Devices" and enable "No FBDI output" in "FBDI Protocol" in the "Data Output" tab.

  • The "Serial, sorted output via FBDI workflow" option must be disabled in Prinect Shooter (default).

You will find this option in the "Administration > Configuration" tab.

Note: The jobs are unsorted when output even if only one of these requirements is met. Your output is not sorted, for example, if the "Serial, sorted output via FBDI workflow" option is enabled but the TIFF-B jobs come from Prinect MetaDimension without an FBDI protocol.

An unsorted output has two variants:

  • Output with an FBDI protocol (enabled in the Prinect MetaDimension Tiff-B Engine Manager) and
  • Output without an FBDI Protocol.

Unsorted output with FBDI protocol

During an unsorted output with an FBDI protocol, the FBDI data provide Prinect Shooter with information about the job context of the single signatures that will be output. In the job list of the Printmanager, unsorted jobs with an FBDI protocol are marked by a yellow folder icon, indicating that the plates belong to one job. When you click the folder icon, the folder expands, and you can see the single component jobs ("plates"). The "Signatures" tab displays only the signature of the component job when you open such a job. Accordingly, you can output separations again only for a component job (see the Reprinting Single Separations).

Note: If you wish to work with the FBDI protocol in Prinect MetaDimension as a rule, you can simply disable or enable the "Serial, sorted output via FBDI workflow" in Prinect Shooter in "Administration > Configuration > Preferences" (see also the "Serial, sorted output via FBDI workflow"). This lets you switch between a sorted and unsorted output as needed without having to change the Tiff-B Export Engine Manager settings in Prinect MetaDimension.

Unsorted output without FBDI protocol

Prinect Shooter has no details about the job context of the single separations if the FBDI protocol is disabled in the Prinect MetaDimension Tiff-B Engine Manager ("No FBDI" option). Only the job name in the job list provides details about the original job to which the color separation concerned was assigned. In this case as well, the color separations are listed separately in the job list. These jobs have ".tif" as their extension there in contrast to jobs that were output unsorted with an FBDI protocol.

Unsorted jobs without an FBDI protocol are displayed in the job list as single component jobs ("Tiff-B Jobs"). Displaying an entire job as one folder is not possible because Prinect Shooter without an FBDI protocol is not given any details about the job context of a single component job.

Reorder unsorted output

During an unsorted output, you can define the output priority for each single separation (component job) by changing the order (see Reordering Jobs).

Assign identification numbers

Prinect Shooter assigns a job number (JobID) to each print job or component job. There are three different cases:

  • The same identification number is assigned to each component job in an unsorted output with an FBDI protocol. The identification number displays in the "ID" column in the job list. This makes it possible to always assign the component jobs to the correct job even if you changed the order of single component jobs (see Reordering Jobs). The component jobs of the current job count in the identification number of the next job. For example, a job is assigned ID 1 and has eight component jobs. The component jobs also are assigned ID 1. The next job (and any component jobs) is assigned ID 9.
  • A specific, consecutive ID is assigned to each component job in an unsorted output without an FBDI protocol.
  • No component jobs are generated in a sorted output and, for that reason, consecutive IDs are assigned to the jobs.
