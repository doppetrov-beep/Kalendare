Complete device list


You can see the following columns in the device list:

  • "Device": Name of the device
  • "Icon": A symbol representing the output device.
  • "Status": Information of the operation status of the output device.
  • "Error message": If an error occurs in the output device, a short text is displayed here indicating the type of the error.

Open the Engine Manager by double-clicking the device entry or by selecting the device entry and click on "Open". More details about configuration of the Engine Manager can be found in the Engine Manager Online Help.
