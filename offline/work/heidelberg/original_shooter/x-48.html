Regional settings

In "Regional Settings", you can select the language of the Printmanager user interface.


Set the language you want in the "Language" list box and click "Apply". A dialog displays telling you that you must first exit the Printmanager before the changes can be applied. Confirm the dialog with "Yes, stop". The Printmanager exits. When the Printmanager is restarted, it displays in the language you just selected.
