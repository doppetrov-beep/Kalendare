Server

Prinect Shooter is based on a client-server architecture. In this process, operations related to job processing are performed by the server component, and the user interfaces as the client applications allow users to access the server component. In the "Administration > System > Server" section you can link the Printmanager user interface to a Prinect Shooter server. Server tasks are processed by programs that are implemented as "Windows Services". You can start or exit these services manually with "Prinect Shooter Service Control". The Prinect Shooter services do not have a user interface of their own. This makes it possible on the one hand to run Prinect Shooter without a user interface in the hot folder mode or on the other to use different user interfaces to control the software. These interfaces are the Printmanager or browser user interface (of the local computer or another one in the network). By assigning different permissions, you can also control Prinect Shooter at the same time through different user interfaces.

The Printmanager can control the Prinect Shooter software only if it is linked to a server on which the Prinect Shooter service is installed and running. For that reason, "Administration System > Server" is always the first view that you see when the Printmanager is launched.


Normally the Printmanager is automatically connected to the server that it was last logged in to. The Printmanager is not automatically connected to a server when it launches the first time after an installation or upgrade installation. In this case, you must select a server and connect it manually.

Click "Select local server" if you wish to log in to the local server. This lets you establish a connection without having to know the network name or IP address of the local server.

Connection to a Different Prinect Shooter Server

The "Server Name" list shows the active Prinect Shooter systems that you have in one network. Select the row you want and then click "Select" to select a Prinect Shooter server that you would like to "remote control" instead of the local server. After selection, your local Prinect Shooter Printmanager establishes the connection to the selected server and displays the server's data.

Click the "Select by IP Number" button if you wish to select a Prinect Shooter server by an IP number or have to because, for example, the server is not in the list or your network doesn't support administration by name.


You can type the IP number of the server in the "Select IP number" dialog. Confirm the dialog with "OK". Ask your system administrator for the IP number of the Prinect Shooter server you want if you are not sure of it.

The "Refresh" button updates the server list and includes Prinect Shooter servers which were started after the Server view was called up.

After the connection is established, you must enter a registered user name and the corresponding password (see the User Management).

Store password for automatic Login

You can enable "Store password for automatic Login" if you are sure that there will be no unauthorized access to Prinect Shooter in your work environment. In this case, no user name and password are requested the next time you start the Printmanager if the Printmanager is connected to the same server. The Printmanager then launches using the user name and password and the permissions (see the User Management) of the last user logged in.

Logoff

Use "Log Off" to disconnect the Printmanager user interface from the selected Prinect Shooter server. You must log off, for example, if you wish to log in with another user name and password (and perhaps different permissions) or if you wish to "switch" the Printmanager to another server. The Printmanager is automatically disconnected from the Prinect Shooter service when you exit the Printmanager. This means that you must connect to a server every time you start the Printmanager user interface and log in accordingly (except if the password was stored).
