Starting and Terminating Programs

When the Prinect Shooter software is installed successfully, you will find the name Prinect Shooter plus related menu items in the Windows Start menu. You will also find the "Prinect Shooter" folder on the Windows desktop; this has the same entries as the Prinect Shooter Start menu. In this way, you can choose whether you wish to call up the various applications from the Start menu or by double-clicking the desktop folder.

The Prinect MetaDimension Start menu contains the menu items listed below:

  • Uninstall Prinect Shooter
  • Save Configuration

Saves the current configuration.

  • Restore Configuration

Restores a saved configuration.

  • Modify License Server

If you wish to use a different License Server to the one set during installation, you can change the connection to the License Server with this menu item.

  • Modify Folder Selection

This menu item allows you to change certain system folders that were set up during installation. You can change the following folders:

  • Prinect Shooter Printmanager

You start the Printmanager with this menu item. This lets you define all your system configuration settings and monitor job processing. To be able to start the Printmanager, the Prinect Shooter service must be started.

  • Prinect Shooter Service Control

You can use this program to manually start or stop the Prinect Shooter service. To start, simply click the green "arrow key", to stop click the red "stop key". Normally, the Prinect Shooter service is automatically started when the computer is starting up.

  • Web UI

You start the browser user interface with this menu item. This lets you define your system configuration settings and monitor job processing. To be able to start the browser user interface, the Prinect Shooter must be started.

  • Service > Remote Service

With Remote Service, Heidelberg provides a remote tool that can be used for support of this product. Contact your local Heidelberg agent if you need support.

The License Manager is installed in addition to the Prinect Shooter software. By doing this, you install not only the Prinect Shooter Start menu but also the Heidelberg Prinect Licensing Start menu. You can call up the License Manager in this menu.

You must install the Prinect TIFF Toolbox software separately if it is required. This application will also have its own Start menu.

Starting the Printmanager

On the Prinect Shooter PC, select "Start > All Programs > Heidelberg Prinect Shooter > Prinect Shooter Printmanager" in the Windows Start menu. Alternatively, you can launch the Printmanager in the "Heidelberg Prinect Shooter" startup group on the desktop.

Prinect Shooter only runs locally on the Prinect Shooter PC because the Engine Manager communicates directly with the output device via the interface card. You can also "remote control" this Prinect Shooter from another computer that also has an installed Prinect Shooter system and that can be accessed in the network by selecting this computer in the Printmanager there in "Administration > System > Server" and logging into this server (see also the Connection to a Different Prinect Shooter Server).

Store password for automatic Login

You can enable "Store password for automatic Login" if you are sure that there will be no unauthorized access to Prinect Shooter in your work environment. In this case, no user name and password are requested the next time you start the Printmanager if the Printmanager is connected to the same server. The Printmanager then launches using the user name and password of the last user logged in.

MDS User

In a Prinect workflow system configuration, you can also log in to Prinect Shooter as an MDS user (a user set up in the Prinect Master Data Store). You can find more details about MDS user management in the documentation for the Prinect product that was used to install the Master Data Store (e.g. Prinect MetaDimension or Prinect Integration Manager).


Prerequisite: You must have first set up a connection to the Master Data Store (MDS) (see Prinect Services).
