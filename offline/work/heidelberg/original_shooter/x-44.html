Configuration

To go to "Configuration", click the "Administration" button in the operating panel and go to the "Configuration" tab.


In the "Configuration" tab, you can set up virtual printers, define preferences, set up the drive monitor, select the language for the Printmanager user interface, connect Prinect Shooter to a Prinect Prepress Manager or a Prinect Integration Manager and create a connection to a Prinect Master Data Store ("MDS").
