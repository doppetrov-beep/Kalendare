Components

Prinect Shooter consists of the following components:

Hardware components:

  • Prinect Shooter PC with
  • Interface card and connection cable for connecting the output device.

Software components:

  • Printmanager (Java user interface): You can launch and operate the Printmanager locally on the Prinect Shooter PC.
  • Browser UI: The Browser UI of Prinect Shooter was implemented as a web browser application. This makes remote operation of the Prinect Shooter user interface possible from other computers through the network.
  • Engine Manager: Device management for the connected output device.
  • Service Control: Program for starting and stopping the Prinect Shooter services.

Additional software:

  • Prinect Tiff Toolbox: The Prinect Tiff Toolbox allows you to view Tiff-B files and prepare them for optimal output with Prinect Shooter.

Functional components:

  • Virtual Printers
  • Drive Monitor
  • User Management
  • E-mail notification if system faults occur

You will find detailed information about the components listed in the following sections of the manual or in the online documentation.
