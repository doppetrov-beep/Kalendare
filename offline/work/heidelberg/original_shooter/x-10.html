JDF (Job Definition Format) Support

Prinect Shooter is prepared for connection to JDF -based workflow systems such as Heidelberg's Prinect Integration Manager. In a configuration with the Integration Manager, you need a Prinect Renderer or a Prinect MetaDimension RIP to create the Tiff-B screening data.


The exchange of data between Prinect Integration Manager/Prinect Integration Manager S and Prinect MetaDimension is based on the "Job Definition Format (JDF)". For that reason, the Prinect Shooter software contains a "JDF Portal" where this interface is configured.

While the exchange of data between the Prinect Integration Manager or Prinect Integration Manager S is solely through the JDF portal, a File Based Device Interface (FBDI) can be used for the exchange of data between Prinect MetaDimension and Prinect Shooter You can configure how the FBDI interface will be used in Prinect MetaDimension in the TIFF-B-Export Engine Manager. If an FBDI output is enabled, Prinect MetaDimension creates a JDF document containing all the important job data for every job it sends to the Prinect Shooter.

Note: You can connect several Prinect Shooters to an Integration Manager or a Prinect MetaDimension RIP. In this way, you can control a number of Prinect Shooters with a connected Heidelberg imagesetter with just one Prinect MetaDimension system.

If you wish to connect a Heidelberg imagesetter to a workflow system or a RIP of another make via Prinect Shooter, this RIP must be able to generate TIFF-B data. Use the "Prinect TIFF Toolbox" software to check the TIFF-B bitmaps and, if necessary, prepare them so that they can be output with Prinect Shooter if this is possible at all.

Prinect Shooter sends data about the imaging status and any device errors, etc. to the connected workflow system. (What device information is sent, and whether you can send it at all, depends on your connected output device.) The "Job Messaging Format (JMF)" is used for this. Vice versa, Prinect Integration Manager or Prinect MetaDimension can, for example, trigger a reprint of a single separation at the Prinect Shooter.

In addition, Prinect MetaDimension (but not Prinect Integration Manager/Prepress Manager S) can send information about the job context of single separations to Prinect Shooter via an FBDI protocol (see the Sorted and Unsorted Output).

Note: You can follow the imaging process in the progress bar in the Prinect MetaDimension job list if "Supervised FBDI output" is enabled in the Prinect MetaDimension Tiff-B Engine Manager. In other words, a job's status is "done" only if imaging was finished successfully. In the case of a non-supervised FBDI output or an output without an FBDI protocol, a job in the Prinect MetaDimension job list is only given the status "done" if Tiff-B data were created. Imaging can no longer be checked in Prinect MetaDimension. To do this, you must launch one of the Prinect Shooter user interfaces (Printmanager or browser user interface).

The FBDI format and the JMF format are components of the JDF specification. Through JDF support, Prinect Shooter fits into a JDF-based overall workflow such as is implemented in the Heidelberg Prinect System.

You can link Prinect Shooter to the Prinect MDS server if Prinect Shooter is run in a Prinect system environment with a "Master Data Store" (MDS) (see also the Prinect Services). In this case, Prinect Shooter sends device information to the Master Data Store so that this information is available from a central source in the Prinect system environment. Prinect Shooter also uses the joint user management of the Master Data Store (see the Prinect Permissions Structure (Managed in the Master Data Store)).
