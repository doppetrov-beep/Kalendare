Export of Tiff-B Files

You can export Tiff-B files for external archiving or for further processing using suitable tools from the Prinect Shooter workflow.

Procedure:

1. Mark a Tiff-B export job in the job list and select "Export" in the context-sensitive menu.

2. In the "Choose Export Directory" dialog, select a folder which will hold the exported Tiff-B files. The export folder can also be located on a different computer in your network environment.

If necessary, you can create a new export folder in the "Choose Export Directory" dialog.

The original TIFF-B file name is kept during export. An exported job contains all the data needed for imaging.

You can output an exported TIFF-B job again with Prinect Shooter by copying or moving the job to a Prinect Shooter hot folder.
