JDF Portal Settings

Prinect Shooter can report details about re-imaged plates or films like material name, material size, type (plate/film) and the time of imaging to an MIS or to Heidelberg Analyze Point through the JDF portal. It also reports type details (aluminum/polyester) for plates.

The details about re-imaging sent through the JDF portal contain the job context of the original print job. In other words, if jobs were created in conjunction with a Prinect workflow system, e.g. with the Prinect Integration Manager, details such as Job ID, JobPartID, Layoutname, SignatureName, SheetName, Side, Separation or language version are also sent to the MIS or Analyze Point. Based on these details, re-imaged plates or films can be assigned clearly to the original job.

Note: JDF is an XML-based data format that combines the job ticket specifications with a message description standard and a message interchange protocol. JDF is a further development of well-known technologies such as CIP3 PPF and the Adobe Portable Job Ticket Format (PJTF).

To connect Prinect Shooter to a Prinect system environment through the JDF portal, you must register Prinect Shooter at a Prinect Integration Manager. To do this, in the "Server" group, select the Prinect Integration Manager server on which you wish to register Prinect Shooter. If there are several Prinect Integration Manager servers in your system environment, all the Prinect Integration Manager servers that are located in the network environment are listed. You can start a server query again with "Refresh" if you cannot find a certain server in the list.

To connect Prinect Shooter to a Prinect system environment through the JDF portal, you must register Prinect Shooter at a Prinect Integration Manager. To do this, in the "Server" group, select the Prinect Integration Manager server on which you wish to register Prinect Shooter. If there are several Prinect Integration Manager servers in your system environment, all the Prinect Integration Manager servers that are located in the network environment are listed. You can start a server query again with "Refresh" if you cannot find a certain server in the list. Select the server that you wish to log in to and click "Execute". The "Join Prinect" program opens via the network connection to the selected server. A Windows security alert first displays. This dialog draws your attention to the fact that Windows Firewall has blocked "Join Prinect". Windows assumes that it could be a malware, e.g. a Trojan, and would like to block communication from "Join Prinect" by Windows Firewall. Click "Unblock". Prinect Shooter is connected to a Prinect Integration Manager with "Join Prinect". You will find details about connection to a Prinect Integration Manager in the Connection of Prinect Shooter to a Prinect System Environment.
