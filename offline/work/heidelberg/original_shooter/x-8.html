Functionality and Structure of the Prinect Shooter

Prinect Shooter is an output workstation that downloads screened imaging data to a high-resolution output device. It is the link between a workflow system (e.g. Prinect Integration Manager) or a Raster Image Processor (RIP) (e.g. Prinect MetaDimension) and a Heidelberg output device.
