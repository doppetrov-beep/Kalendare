Prinect Shooter Print Manager user interface (Java UI)

The user interface of the Prinect Shooter Printmanager consists of "static" and "dynamic" elements. The static elements are always visible while the dynamic elements can change their appearance and contents depending on the operational process that is currently in progress.


The user interface has the following static elements:

  • the operating panel and
  • the status panel

The user interface has the following dynamic elements:

  • the dynamic window and
  • the dynamic control area.
