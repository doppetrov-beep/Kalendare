User Interfaces

Prinect Shooter has two user interfaces:

Printmanager

The Printmanager has a greater number of features and is very easy to operate. The Printmanager can either run locally on the Prinect Shooter PC or you can "remote control" it on another Prinect Shooter by selecting another Prinect Shooter server in "Administration > System > Server" and logging in to it (see the Server).

Additional features of the Printmanager:

  • Unlike in the browser user interface, you can manually sort jobs in the Printmanager by dragging-and-dropping them. This lets you define your output priority.
  • The Printmanager also has a special Bitmap Viewer that lets you check the TIFF-B bitmaps of the jobs on the screen before they are output. This Bitmap Viewer includes a zoom function that you can use to scale up the view of the bitmaps to pixel size.

Browser UI

This user interface is opened in any web browser and can be launched on every computer that has a suitable browser and that is located in a common network environment to the Prinect Shooter PC. The following browsers are supported:

  • Microsoft Internet Explorer 6.0 or later,
  • Mozilla Firefox as of 1.0,
  • Opera 9.0 or later,
  • Mozilla 1.7 or later.

Of course, this user interface can also be launched on the Prinect Shooter PC. The browser user interface allows remote control and monitoring of the Prinect Shooter, for example, from a DTP computer.

Properties of the Printmanager User Interface

You can perform the following operations in the Printmanager user interface:

  • Watch or monitor jobs or component jobs.
  • View job data.
  • View job details.
  • View a job preview.
  • Reprint jobs or component jobs.
  • Pause and continue jobs or component jobs.
  • Move jobs to the Depot tab.
  • Configure a period for job processing.
  • Export jobs.
  • Delete jobs or component jobs.
  • Change the job order by resorting them.
  • View statistics about material consumption.
  • Create a job report.
  • View the output device installed on the Prinect Shooter PC and create an IPR device profile.
  • Set and monitor the drive monitor of Prinect Shooter.
  • Set up, change and delete virtual printers
  • Manage the users of Prinect Shooter.
  • Configure the e-mail notification service
  • Set options for pausing jobs.
  • Change the priority of single jobs. By doing this, you modify the order the jobs are processed in.

In addition, you can output a job or a single plate immediately in the Printmanager if you assign it an "urgent" priority (see the Printing "Urgent" Jobs Next).

Prinect Shooter Service Control

You can use service control to manually start or stop the Prinect Shooter system services. The system is only functional when the Prinect Shooter services are active.

The "Report" button lets you create a "service report" that can help with servicing if problems occur. In contrast to a job report, a service report does not have any job-specific information. You can find detailed information about this in the Creating a Job Report.

Virtual Printers

Virtual printers are the "input channels" of the Prinect Shooter. The Tiff-B jobs are sent to the Prinect Shooter through hot folders. To do this, you first create an output folder on the PC on which the Raster Image Processor (RIP) is running and enable it in the network. Then you map this folder as a mapped volume to the Prinect Shooter PC. After this, you configure a virtual printer in the Prinect Shooter user interface and assign it to the mapped volume. The shared volume now becomes the "hot folder". This means that Prinect Shooter checks whether Tiff-B data were transferred to this folder and processes them automatically. For more details about sharing an output folder, see the Opening a Virtual Printer or Creating a New One.

You can create several virtual printers, for example, to manage different plate sizes or punch settings separately.

Drive Monitor

You can use the drive monitor to monitor the capacity of the local hard disk drives of the Prinect Shooter PC. You can use this tool to prevent one of the system's hard disks "overflowing" with data so that as a result the system may not be able to continue to work. If the data load on a monitored drive exceeds a preset limit, job processing in the Prinect Shooter is stopped and you will be given the opportunity to free some space on the drive in question.
