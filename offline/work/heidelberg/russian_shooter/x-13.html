Менеджер двигателей

Связанным снимком управляет так называемый «Менеджер двигателей». Менеджеры двигателей - это программы, которые проверяют поток данных на выходное устройство и в которых вы можете установить конкретные выходные параметры устройства. Вы также можете контролировать определенные функции устройства для некоторых устройств вывода, например, подачу материала и резку для устройств обработки изображений.

Для Prinect Shooter доступны следующие менеджеры двигателей:

  • Руководитель Speedway Engine
    для диктофонов со связью Speedway (Heidelberg Suprasetter and Prosetter platesetters, Heidelberg Primesetter, Herkules, Duosetter filmetters)

С помощью диспетчера двигателя вы можете, например, выполнять следующие задачи:

  • Мониторинг состояния обработки в устройстве вывода
  • Управляйте снимателем (остановка для изменения материала, продвижение, резка...)
  • Установите параметры позиционирования страницы (расстояния между страницами, режим сбора)
  • Установите параметры выходных материалов (планшет, пленка, фольга) и протестируйте их (невозможно для всех устройств обработки изображений в диспетчере двигателей).
  • Определение шаблонов для настройки параметров удара и смещения

Примечание: Не все варианты, перечисленные выше, доступны для всех устройств вывода. Некоторые менеджеры двигателей имеют дополнительные параметры настройки. Для получения более подробной информации о том, как работать с версиями Engine Manager, пожалуйста, обратитесь к соответствующей онлайн-помощи Engine Manager.

Поскольку требуемый менеджер двигателя зависит от устройства вывода, соответствующий менеджер двигателя устанавливается вместе с основным программным обеспечением Prinect Shooter.
