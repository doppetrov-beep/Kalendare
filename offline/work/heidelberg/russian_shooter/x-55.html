Управление пользователями

Администрирование разрешений для Prinect Shooter осуществляется в разделах «Пользователи», «Группы» и «Разрешение». Prinect Shooter имеет собственную администрацию пользователя. Это означает, что вы можете самостоятельно определять и управлять своими пользователями в Prinect Shooter. Вы можете использовать пользовательские данные Магазина данных, если есть подключение к такому магазину (см. Услуги Prinect).

Концепция управления пользователями и структура разрешений

Примечание: Вы найдете подробную информацию о настройках пользовательского интерфейса в Пользователи.

Управление пользователями для Prinect Shooter не имеет ничего общего с управлением пользователями вашей операционной системы. Для лучшего обзора вашей работы может быть хорошей идеей использовать те же имена пользователей и пароли в управлении пользователем Prinect Shooter и в вашей операционной системе.

В управлении пользователями всегда делается разница между сохранением и управлением пользовательскими данными Prinect Shooter локально на вашем ПК Prinect Shooter и централизованно на сервере основных данных (MDS) (см. также: WEB ). Услуги Prinect).

  • Местное управление пользователями
    • Тип: "местный"

Данные пользователя хранятся локально на вашем компьютере.

  • MDS (Master Data Store) для управления пользователями
    • Тип: "MDS"

Предварительное условие: Имеется подключение к серверу MDS (см. Услуги Prinect).

Основные данные Prinect Shooter и пользовательские данные хранятся на сервере MDS.

Структура разрешений Prinect действительна (см. Структура разрешений Prinect (управляется в Магистерском хранилище данных)).

Следующее применимо как для локального, так и для управления пользователями MDS: Разрешения пользователя определяются исключительно принадлежностью к одной из следующих групп разрешений:

  • Группа с разрешения администратора
  • Группа с разрешениями Poweruser
  • Группа с разрешениями пользователей
  • Группа с разрешениями гостей

Разрешения группы основаны на иерархии: разрешения администратора имеют наибольший авторитет, а разрешения пользователей — наименьший.

Вы должны войти в систему в качестве администратора при первом запуске Prinect Shooter Printmanager после установки. Затем вы можете создать новых пользователей и назначить каждого пользователя в группу разрешений.

Структура разрешений Prinect (управляется в Магистерском хранилище данных)

Пользователи MDS, созданные в приложении Prinect, хранятся на сервере MDS. Они доступны для всех других приложений Prinect, подключенных к серверу MDS.

В структуре разрешений MDS следующие группы разрешений являются обязательными для всех приложений Prinect. Управление пользователями Priect):

  • PrePressАдминистраторы
  • PrePressPowerUsers
  • Препресс-пользователи

Разрешения пользователей MDS управляются автономно каждым приложением Prinect. Это означает, что разрешения, которые есть у пользователя MDS, определяются отдельно в каждом приложении Prinect. Разрешения пользователя MDS определяются с помощью группы, к которой принадлежит пользователь. (Prinect Integration Manager является исключением в системе Prinect.) В этом случае индивидуальные разрешения также могут быть назначены пользователям MDS.

Пример

Prinect Shooter, Prinect Signa Station и Prinect Integration Manager подключены к центральному серверу MDS.

Вы создаете пользователя MDS «HD_Global» в Prinect Shooter и присваиваете его группе разрешений «PrePressUsers».

Пользователь «HD_Global» теперь доступен во всех других приложениях Prinect, которые подключены к серверу MDS, это означает в нашем примере в Prinect Signa Station и Prinect Integration Manager. Другими словами, вы можете войти в систему как «HD_Global» с соответствующим паролем на станции Prinect Signa и в диспетчере интеграции Prinect. Здесь также пользователь «HD_Global» имеет разрешения группы разрешений «PrePressUsers».

Все пользователи во всех приложениях Prinect, которые имеют разрешение администратора, могут назначить пользователя «HD_Global» другой группе разрешений. Это означает, что администратор на станции Prinect Signa, например, может изменить разрешения пользователя «HD_Global» в MDS.

Пользователи

Существующие пользователи перечислены в разделе «Пользователи». Кнопка «Новый» позволяет создать новую учетную запись пользователя.


В дополнение к вводу имени пользователя и пароля вы также определяете в «Типе», будет ли пользователь локальным или MDS-пользователем. Вы можете выбрать «MDS» только в том случае, если Prinect Shooter подключен к серверу MDS. Услуги Prinect).

Колонка «Тип» в списке пользователей отображает вашу настройку.


Когда вы выбираете пользователя, группы разрешений, которые вы можете назначить этому пользователю, отображаются в «Доступных группах». Вы можете назначить одну или несколько групп разрешений пользователю с помощью «Добавить». Вы можете отменить назначенную группу (группы) разрешения с помощью «Удалить».

Для получения дополнительной информации об администрировании пользователей и групп см. Управление пользователями и группами.

Группы

Существующие группы разрешений в управлении пользователями перечислены в разделе «Группы».


Когда вы выбираете группу, пользователи, которым вы можете назначить эту группу, показаны в разделе «Доступные пользователи». Вы можете назначить одного или нескольких пользователей в группу с «Добавить». Вы можете отменить назначенную группу (группы) разрешения с помощью «Удалить».

Для получения дополнительной информации об администрировании пользователей и групп см. Управление пользователями и группами.

Управление пользователями и группами

Следующие три примера будут использованы для описания процедуры управления пользователями и группами.

По сути, вы можете выполнить следующие действия:

  • Создать пользователя

Видишь? «Пользователи»: Пример 1: Создание нового пользователя.

  • Назначение пользователя в группу разрешений. Пользователь имеет все разрешения этой группы разрешений.

Видишь? "Пользователи": Пример 2: Назначение пользователя в группу разрешений..

  • Назначение одного или нескольких пользователей в группу разрешений. Все назначенные пользователи имеют разрешения этой группы.

Видишь? «Группы»: Пример 3: Назначение нескольких пользователей одновременно в другую группу разрешений.

"Пользователи": Пример 1: Создание нового пользователя

Примечание: У вас должны быть разрешения администратора на действия, приведенные в примерах.

В этом примере будет создан следующий пользователь:

  • Имя пользователя: «HD_Admin»
  • Пароль: «Принц»
  • Домен: «локальный» (управление локальными пользователями)

1. Выберите вкладку «Пользователи» слева. Вы увидите список всех определенных пользователей на этой вкладке.

2. Нажмите «Новый», чтобы создать нового пользователя.

3. Введите «HD_Admin» в качестве имени пользователя, «Prinect» в качестве пароля, «local» в качестве домена и нажмите «OK».

Затем вы увидите нового пользователя «HD_Admin» в списке определенных пользователей. Пользователю «HD_Admin» сначала присваиваются разрешения группы «Пользователей». Вы можете изменить эти разрешения позже, назначив другую группу разрешений пользователю «HD_Admin».

4. Вы можете определить свойства для каждого пользователя. Дважды щелкните пользователя в списке пользователей или нажмите «Свойства». Примите к сведению следующие пункты:

    • «Включено»: В списке пользователей столбец «Включено» показывает, установлена эта опция или нет. Если пользователь включен, он / она может войти в Prinect Shooter Printmanager. Вы также можете отключить пользователей с этой опцией, не удаляя учетную запись пользователя со всеми ее свойствами.
    • «Подробности»: Вы можете ввести информацию об этой учетной записи пользователя в это поле, например, чтобы указать на действия этой учетной записи пользователя. Эта информация отображается в столбце «Подробности» в списке пользователей.
    • «Адрес > Имя»: этот ящик заполняется автоматически, если вы вводите «Первое имя» и «Семейное имя» в «Лицо».

5. Вы можете изменить пароль каждого пользователя. Для этого выберите пользователя в списке пользователей, а затем нажмите «Изменить пароль». Введите новый пароль и подтвердите его с помощью «ОК».

6. Вы можете удалить каждого пользователя, которого вы создали. Для этого выберите пользователя в списке пользователей, а затем нажмите «Удалить».

"Пользователи": Пример 2: Назначение пользователя в группу разрешений.

Пользователь «HD_Admin» из примера 1 должен иметь права администратора.

1. Выберите вкладку «Пользователи» слева.

2. Нажмите на пользователя «HD_Admin». Доступные группы разрешений приведены в разделе «Доступные группы». Вы можете воспользоваться кнопкой «Добавить».

3. Нажмите «Пользователи» в списке «Член», а затем нажмите «Удалить».

4. Нажмите «Администраторы» в списке «Доступные группы», а затем «Добавить». Это название группы теперь добавлено в список «Члена».

5. Нажмите «Применить». Пользователь «HD_Admin» теперь является членом группы «Администраторы».

6. Чтобы снова удалить пользователя «HD_Admin» из группы «Администраторы», пометьте имя пользователя, выберите эту группу в списке «Член» и нажмите «Удалить».

"Группы": Пример 3: Назначение нескольких пользователей одновременно в другую группу разрешений

Примечание: Вкладка «Группы» используется в основном для назначения нескольких пользователей в новую группу разрешений. Чтобы назначить одного пользователя другой группе разрешений, перейдите на вкладку «Пользователи» и назначьте пользователя, как описано в Примере 2.

«HD_User_1», «HD_User_2» и «HD_User_3» являются членами группы «Администраторы». Вы собираетесь удалить этих пользователей из этой группы и вместо этого назначить их в группу «Пользователей».

1. Выберите вкладку «Группы» слева.

2. Нажмите на группу «Пользователи» в списке групп разрешений.

3. Отметьте «HD_User_1», «HD_User_2» и «HD_User_3» в списке «Доступные пользователи», а затем нажмите «Добавить».

4. Нажмите «Применить». Все пользователи в списке «Члены» становятся членами группы «Пользователи», другими словами, «HD_User_1», «HD_User_2» и «HD_User_3». Поскольку пользователь может быть только членом одной группы, эти пользователи автоматически удаляются из группы «Администраторы».

Таблица разрешений для Prinect Shooter

Сокращения:

  • «Доступ»: все разрешения
  • "restr. access (1)": Все разрешения, но удаление изображений не представляется возможным.
  • "restr. access (2)": Все разрешения, но опция "Выбрать по IP номеру" затемнена. Это означает, что при выборе сервера вы не можете выбрать компьютер Prinect Shooter по номеру IP.
  • "restr. access (3)" - все разрешения, которые ограничены собственной учетной записью пользователя.
  • «Доступ (4)»: все разрешения, но пароли других пользователей могут быть изменены только в том случае, если исходный пароль известен.
  • «Readonly»: только для чтения
  • Нет входа: нет разрешений
