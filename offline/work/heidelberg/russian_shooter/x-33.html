Экспорт Tiff-B файлы

Вы можете экспортировать файлы Tiff-B для внешнего архивирования или для дальнейшей обработки с помощью соответствующих инструментов из рабочего процесса Prinect Shooter.

Процедура:

1. Отметьте экспортную работу Tiff-B в списке заданий и выберите «Экспорт» в контекстно-чувствительном меню.

2. В диалоговом режиме «Выбрать экспортный каталог» выберите папку, в которой будут храниться экспортируемые файлы Tiff-B. Экспортная папка также может быть расположена на другом компьютере в вашей сетевой среде.

При необходимости можно создать новую экспортную папку в диалоговом режиме «Выбрать экспортный каталог».

Исходное имя файла TIFF-B сохраняется при экспорте. Экспортируемая задание содержит все данные, необходимые для визуализации.

Вы можете снова вывести экспортную работу TIFF-B с помощью Prinect Shooter, скопировав или переместив работу в горячую папку Prinect Shooter.
