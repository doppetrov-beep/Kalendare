E-Почта

Если на вашем компьютере Prinect Shooter есть подключение к электронной почте, вы можете настроить Prinect Shooter так, чтобы электронное письмо отправлялось до четырех получателей, если во время обработки работы произошла ошибка. В этом электронном письме содержится короткий текст, описывающий ошибку.

Эта функция позволяет быстро реагировать на ошибки, даже если никто не контролирует Prinect Shooter.


Установка адреса отправителя

В разделе «адрес отправителя электронной почты» вы присваиваете функции электронной почты данные доступа пользователя электронной почты. Здесь вы должны ввести пользовательские данные, которые обеспечивают доступ к электронной почте в локальной системной среде.

Примечание: Попросите вашего системного администратора правильно ввести данные об адресах электронной почты.

  • "Адрес электронной почты":

Введите действительный адрес электронной почты в этом поле. Prinect Shooter использует этот адрес как адрес отправителя. Эта информация необходима для функции электронной почты.

  • "SMTP Host":

Введите SMTP-хост, через который вы можете отправлять электронные письма. Эта информация необходима для функции электронной почты, поскольку электронные письма распространяются через хост SMTP. Если вы не уверены, обратитесь за помощью к системному администратору.

  • "POP3 Host":

Вы должны заполнить хост POP3, имя пользователя и пароль только в том случае, если для отправки электронных писем требуется «POP3 перед SMTP». В этом случае аутентификация отправителя электронной почты запрашивается сервером POP3. Чтобы включить эту опцию, введите хост POP3, связанный с адресом электронной почты отправителя. Если вы не уверены, обратитесь за помощью к системному администратору.

  • "Имя пользователя":

Введите имя пользователя для адреса электронной почты. Эта информация не нужна для каждой учетной записи электронной почты.

  • "Пароль":

Введите пароль POP3, связанный с именем пользователя. Эта информация не нужна для каждой учетной записи электронной почты.

Примечание: Расширенный SMTP (eSMTP) с защитой паролем в протоколе SMTP не поддерживается Prinect Shooter.

Установка получателей уведомлений

В "Получатель уведомлений" можно ввести адреса электронной почты до четырех получателей. В качестве получателей вы можете, например, ввести пользователей DTP, которые печатают через Prinect Shooter.

Присвоение событий уведомления

В "В разделе "тип уведомления" вы можете назначить четырем возможным получателям электронной почты различные сообщения о событиях. Возможны следующие типы событий:

  • "Устройства":

Эти ошибки сообщаются соответствующим устройством вывода на Prinect Shooter во время вывода и передаются по электронной почте.

Пример: Если кассета поставки снимка пуста, генерируется сообщение об ошибке устройства.

  • "Джоб Аборт":

Сообщение об ошибке генерируется, если обработка работы прерывается из-за ошибки в Prinect Shooter.

  • "Предупреждение монитора движения":

Если значение оповещения, установленное для диска, контролируемого монитором диска, было превышено, Prinect Shooter останавливает обработку дальнейших заданий. Это событие может быть передано по электронной почте.
