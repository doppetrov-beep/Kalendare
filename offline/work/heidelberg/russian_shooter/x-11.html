Компоненты

Prinect Shooter состоит из следующих компонентов:

Аппаратные компоненты:

  • Prinect Shooter для ПК
  • Интерфейсная карта и соединительный кабель для подключения выходного устройства.

Программные компоненты:

  • Printmanager (пользовательский интерфейс Java): Вы можете запустить и управлять Printmanager локально на ПК Prinect Shooter.
  • Browser UI: Browser UI Prinect Shooter был реализован как приложение для веб-браузера. Это делает возможной удаленную работу пользовательского интерфейса Prinect Shooter с других компьютеров через сеть.
  • Менеджер двигателей: Управление устройствами для подключенного устройства вывода.
  • Управление сервисом: программа запуска и остановки Услуги Prinect Shooter.

Дополнительное программное обеспечение:

  • Prinect Tiff Toolbox позволяет просматривать файлы Tiff-B и готовить их к оптимальному выходу с помощью Prinect Shooter.

Функциональные компоненты:

  • Виртуальные принтеры
  • Монитор вождения
  • Управление пользователями
  • Уведомление по электронной почте при возникновении сбоев в работе системы

Подробную информацию о компонентах вы найдете в следующих разделах руководства или в онлайн-документации.
