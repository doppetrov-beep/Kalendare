# Мои смены — календарь для iPhone

Мобильный календарь рабочих смен со сменами **3 дня → 3 ночи → 3 выходных**, расчётом дохода, персональными заметками на каждый день и расписанием трёх бригад.

## График

По умолчанию 21 октября 2026 г. — первый день дневной смены бригады №1. На эту дату:
- Бригада 1 работает днём.
- Бригада 2 работает ночью.
- Бригада 3 отдыхает.

Каждые три дня бригады переходят на следующий участок цикла: день → ночь → выходные. На любую дату всегда есть одна дневная, одна ночная и одна отдыхающая бригада.

Имена бригад меняются через ⚙ **Настройки**. Названия в программе по умолчанию обезличенные — можно вписать свои имена. Там же можно изменить первый день цикла и ставку (изначально 3 800 ₽ за смену).

Верхняя карточка показывает сегодняшние назначения, а выбор даты в календаре — расписание на эту дату. Расписание привязано к календарной дате, а не к точному времени начала/окончания смены. Чтобы определить работника **именно в данную минуту**, понадобятся часы начала дневной и ночной смены.

## Заметки

Нажмите на дату и введите текст в разделе «Заметки по датам». Записи сохраняются автоматически на устройстве. Даты с заметками отмечены точкой, а под редактором показан список записей за выбранный месяц.

## Работа офлайн

После первой успешной загрузки на iPhone веб-приложение кэширует основные файлы с помощью service worker. При временном отсутствии интернета может открыться из этого кэша, включая график, имена бригад и заметки. Для обновлений и повторной установки кэша нужен интернет.

Ставка, дата начала цикла, имена бригад и заметки хранятся **локально** в браузере/установленном веб-приложении с помощью localStorage. Эти данные **не отправляются на сервер GitHub** и не синхронизируются между устройствами. При очистке данных Safari, удалении веб-приложения или очистке хранилища системой записи могут пропасть. Данные Safari и установленного на экран Домой приложения могут быть раздельными.

## Основные файлы
- `index.html` — интерфейс, заметки, расчёт дохода и распределение трёх бригад
- `manifest.webmanifest` — настройки веб-приложения
- `service-worker.js` — локальный офлайн-кэш
- `icon-192.png`, `apple-touch-icon.png` — иконки

Сайт полностью статический. Для хранения заметок не нужен сервер.
