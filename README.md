# Мои смены — календарь для iPhone

Мобильный календарь со сменами **3 дневные → 3 ночные → 3 выходных**, с расчётом дохода и настройками ставки и даты начала цикла.

- Исходная дата: 21.10.2026 (первая дневная смена)
- Оплата по умолчанию: 3 800 ₽ за смену
- Данные настроек сохраняются только на устройстве в браузере
- Можно использовать без интернета после первой успешной загрузки

## Размещение на GitHub Pages

Откройте **Settings → Pages** этого репозитория и укажите **Build and deployment → Source: Deploy from a branch**, **Branch: main**, папка **/(root)**, затем **Save**.

Адрес после публикации: https://doppetrov-beep.github.io/Kalendare/

На iPhone откройте адрес в Safari и выберите **Поделиться → На экран «Домой»**.

## Исходные файлы

- `index.html` — интерфейс и расчёт смен
- `manifest.webmanifest` — параметры веб-приложения
- `service-worker.js` — офлайн-кэш
- `icon-192.png`, `apple-touch-icon.png` — иконки приложения

Сайт полностью статический и не отправляет данные о сменах на сервер.
