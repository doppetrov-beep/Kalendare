# Справочники Heidelberg

Архив `Heidelberg_RU_EN.zip` содержит автономные справочники Suprasetter A52/A74/A75 и Prinect Shooter. Скачайте ZIP, распакуйте его целиком и откройте `index.html`.

Русский перевод преимущественно машинный и не прошёл полную техническую вычитку. Важные операции и предупреждения необходимо сверять с английским оригиналом; кнопки внутри справочника переключают язык. Текст на иллюстрациях остаётся на английском.
